# 武艺天赋 1.66.0 实现要求

Peter 2026-10-29 任务 3「加入一些可以提升强度的特性」。全部由线程自行决定。
设备版本前置：1.65.0（六维乘法倍率）完成后再动手，等协调方 GO。
文字规则：只写「成功率 X%」「+N%」，不出现 d20 / 掷骰 / 检定 / DC。

## 一、定位

现有强力特性（金 / 紫 / 天命 / 稀有天赋 / 诅咒）共用一个名额 `LP_PowerTrait`，每人最多 1 个，而且大部分是「属性点效率」类，前期看不出强。
本版新增一个**独立名额**「武艺天赋」（蓝色 #5B9BD5，对应稀有度构思里的「稀有」档）：

- exclusionTag `LP_CombatGift`，每人最多 1 个，**和 LP_PowerTrait 并存**（一个人可以同时有 1 个强力特性 + 1 个武艺天赋）。
- 不占原版特性格子以外的东西；commonality 0，生成后缀里自己掷（仿 HeroTraits.Roll）。
- 三个阶段，随冒险者成长变强：**入门**（获得时）→ **精通**（冒险者 10 级，数值 ×1.5）→ **化境**（传奇冒险者，数值 ×2）。属性类天赋 +2 → +3 → +4。
- 和 1.65.0 的六维乘法倍率（每 +1 约 ×1.15）叠加：属性 +2 ≈ ×1.32，+4 ≈ ×1.75。

## 三、获得途径

- 开局殖民者：35%。
- 普通生成的人形：8%（传奇种族 4%）。
- 冠军 / 首领 / 传奇怪人形：50%。
- 战斗觉醒：没有武艺天赋的殖民者，累计击杀 100 / 300 人形时各一次 25% 成功率觉醒；完成任何 DND 里程碑时 25%。
- 巨灵许愿「让我更强」多一个选项：赐予一个随机武艺天赋（已有则直接升一阶）。
- 老存档：读档时对现有殖民者补掷一次（35%），只做一次（版本标记），信件列出谁觉醒了什么。

## 四、设置（放进「DND 特性」组，组数不变 19）

- 启用武艺天赋（默认开）。
- 敌人也会拥有武艺天赋（默认开）。
- 普通人形获得率 0–30%（默认 8%）。

敌人 combatPower：每个武艺天赋 +6%，精通 +9%，化境 +12%。
