# DND边缘大陆：夺魂仪式（掠夺特性）构思

> 只是构思，没有改模组。写于 2026-10-27，对照设备 1.58.5（只读查看了 `Source/AbyssRitual.cs`、`HeroTraits.cs`、`HeroTraitsIsekai.cs`、`MindFlayer.cs`、`AbyssTaint.cs`、`Core.cs`）。
> Peter 的原话："构思仪式内容，可以掠夺被施法者的特性"。所有取舍已替 Peter 定好（第十节）。

---

## 零、一句话

在 **1.54.0 的深渊法阵** 上加一种新仪式 **「夺魂仪式」**：把囚犯（或奴隶）放到法阵中央，主祭把对方的一个特性从灵魂里剥出来，**装到自己身上**。目标失去这个特性并受"魂伤"，越珍贵的特性代价越大，金色天命级别的特性会要了目标的命。失败时特性碎掉、主祭被反噬，大失败会把深渊里的东西引过来。

另外顺带两种"反着用"的变体：**「秽魂转嫁」**（把殖民者的坏特性塞给囚犯）和巫妖专属的 **「魂匣藏性」**（巫妖把夺来的特性先存进命匣，以后再赏给手下）。

---

## 一、仪式放在哪：复用深渊法阵

| 候选 | 结论 | 理由 |
|---|---|---|
| **深渊法阵 `LP_AbyssCircle`（1.54.0）** | **主场** | 已有：不依赖 Ideology 的自写 Job、主祭 + 护阵者、"把囚犯扛到法阵上"的祭品搬运（`NextOffering`）、成功率公式（`AbyssRitual.Chance`）、三档结果（成功 / 召来未束缚 / 裂口）、灵魂币、深渊腐化、位面薄弱度。夺魂仪式几乎全部是复用。 |
| 巫妖仪式桌 `LP_Altar` | **副场（只给巫妖）** | 巫妖本来就在命匣上"献祭灵魂"，让巫妖不建深渊法阵也能做，代价改成命匣经验，不吃腐化。见第七节。 |
| 圣坛 `LP_FaithAltar` | 不做掠夺 | 善神不会帮你偷灵魂。只在第九节留一个以后可做的"自愿传承"。 |
| 文化 DLC 仪式（RitualDef） | 不用 | 模组对 Ideology 是可选依赖。装了 Ideology 只额外加历史事件和戒律反应（第八节）。 |

**入口**：深渊法阵的 gizmo 列表里加一个按钮「夺魂仪式」，和现在的「一阶·劣魔群……」并列。点开后：选目标（法阵所在地图上的囚犯 / 奴隶）→ 列出目标身上**可掠夺的特性**和每个的阶数、成功率、后果 → 选主祭 → 开始。主祭把目标扛上法阵，护阵者照旧站四角。

**研究**：不加新研究，用 **深渊学 `LP_Research_Abyssology`**。三阶以上还需要读过 **恶魔学典籍**（任意一本，和召唤恶魔的规则一样）。所以科技页（`LP_FireGiantTech`）不用改位置。

## 二、谁能被夺（目标条件）

**可以：**
- 本殖民地的 **囚犯**（任何派系，包括敌人、拉洛克手下、宿敌冠军）。
- 本殖民地的 **奴隶**（只有装了 Ideology 才有奴隶）。
- 倒地的敌人要先**抓成囚犯**才能上法阵。不做"战场上对倒地者直接施法"，避免和战斗混在一起、避免免费刷。

**不可以：**
| 目标 | 原因（显示在灰掉的按钮上） |
|---|---|
| 自由殖民者、客人、访客 | "他不是你的俘虏"。殖民者之间转移走第九节的自愿传承（以后做）。 |
| 外来者（`Outsiders.Is`：恶魔、魔鬼、妖精、天界） | "外来者的本质不在凡人灵魂里"。和深渊仪式祭品规则一致。 |
| 灵魂已被抵押 / 拿走（`AbyssRaces.SoulGone`） | "这具身体里没有灵魂了"。 |
| 巫妖 | "它的灵魂在命匣里"——**例外**：它的命匣也放在同一个法阵上时可以夺（命匣同时被毁，见第七节）。 |
| 死灵造物、机械体、动物、婴儿 / 儿童（< `Adventurer.MinAge`） | 没有成形的灵魂可剥。 |
| 心灵失聪者 | **可以夺**，但成功率 −20%（"抓不住它的灵魂"）。 |
| 身上还挂着「魂伤」的人 | "灵魂还没愈合"——同一个人每次魂伤结束前不能再夺，防止一个囚犯被反复刷。 |

## 三、能夺哪些特性

### 3.1 四个阶（直接对应深渊仪式的四阶）

| 阶 | 特性 | 基础成功率 | 祭品（除目标本人外） | 主祭腐化 |
|---|---|---|---|---|
| 一阶 | 原版普通特性、其他模组的普通特性、Isekai 白色特性 | 85% | 2 灵魂币 | +5 |
| 二阶 | 1.51.0 四个稀有天赋、1.58.0 紫色特性（加点效率 7 个 + 规则 6 个）、Isekai 紫色 / 稀有特性 | 70% | 6 灵魂币 + 1 恶魔血 | +10 |
| 三阶 | 1.58.0 金色 **英雄之资 / 极致·X**、Isekai 金色原型（主角 / 反派 / 回归者 / 召唤勇者 / 转生者） | 55% | 15 灵魂币 + 1 恶魔血 | +20 |
| 四阶 | 1.58.0 **天命**：预言之子、邪契者、魔网之子（神之勇士见 3.3） | 35% | 15 灵魂币 + 1 神迹残片 | +35 |

成功率 = 深渊仪式原公式（主祭魅力 + 智力调整 ×4%、熟练加值 ×2%、护阵者每人 4%、银边 5%、巫妖 / 六臂蛇人 / 提夫林加成、社交、减薄弱度）**再减目标的抵抗**：
- −（目标感知调整值 + 魅力调整值）×3%（目标意志越强越难剥；没开冒险者系统时按 0）。
- −目标冒险者等级 ×1%（传奇冒险者再 −10%）。
- 目标有 **心智堡垒**（传说事迹）：−20%。心灵失聪：−20%。
- 目标被夺心魔 **支配**（`Hediff_Dominated`）中：+10%（灵魂已经被撬开了）。
- 最终仍夹在 5%～95%。

### 3.2 光谱特性（有程度的原版特性）

勤奋、神经质、乐观、美貌、心灵敏感度、意志等：**按目标的程度原样拿走**。主祭已经有同一光谱时，界面上显示"会把你的『懒惰』换成『勤奋』"，只能换不能叠；换出去的那个程度消失。负面程度（懒惰、悲观……）不能被选来"夺"（没人想要），但能被"转嫁"（第六节）。

### 3.3 不能夺的

| 特性 | 原因 |
|---|---|
| **背景特性**（1.32.0 侍僧、罪犯……八个） | "出身偷不走"。它连着背景故事和专长来源（1.58.1 起源专长），拿走会让两边都对不上。 |
| **传说事迹**（屠龙者、巨人克星……七个，1.58.0 青色） | "事迹是做出来的"。 |
| **神之勇士** | "神的选择不容窃取"。尝试夺它的仪式直接无法开始，界面提示；若以后做第九节的圣坛传承，同神信徒之间可以传。 |
| 百战觉醒（IsekaiKillMilestones）这类按击杀获得的里程碑特性 | 同"事迹"。识别方法：模组前缀白名单 + 下面的 DefModExtension。 |
| 性取向（同性恋、双性恋、无性恋） | 不碰。 |
| 基因或异种型强制给的特性（`forcedTraits` 来自基因） | 基因会马上把它补回去，剥了也白剥；界面显示"来自血脉"。 |
| 神力灌注 `LP_DivineInfusion`（敌人专属） | 不能夺，改成另一种回报：仪式成功时额外掉 1 枚神迹残片（夺不走神力，但能把它震出来）。 |

**扩展口**：新增 `LP_TraitTheftExt`（DefModExtension，挂在 TraitDef 上）：`forbidden`（不能夺）、`tier`（强制阶数）、`killsTarget`。其他模组或以后的新特性只写 XML 就能接进来；没写的按 3.1 的默认归类（`HeroTraits.IsGold / IsPurple / Talents.Is` + Isekai 名单 + 其余算一阶）。

### 3.4 强力特性名额（1.58.0 规则，必须遵守）

金 / 紫 / 1.51.0 天赋共用 exclusionTag `LP_PowerTrait`，**每人最多一个**。所以：
- 主祭身上**没有**强力特性：直接得到。
- 主祭身上**已有**一个：仪式开始前界面红字确认「你的『锋芒』会被挤掉并永远消失」。成功后旧的那个消失（不还给目标、不掉落）。
- Isekai 互斥照旧：拿 天赋·X 而身上有对应的 Isekai 白色属性特性时会被 `HeroIsekaiGain` 拦掉——夺魂仪式在**选择阶段**就预先判断（调用同一套 `HeroIsekai.Blocks` 和 `ConflictsWith`），不让玩家走到最后才发现得不到。
- 天命 × Isekai 金色原型的互斥同样提前判断。

### 3.5 天命的进化

天命有三阶（觉醒 → 显现 → 升华，用 degree 表示）。夺来的天命**回到觉醒阶**，之后按主祭自己的冒险者等级照常进化（10 级显现、传奇冒险者升华）。分支（邪契者的宗主）保留。

**邪契者附带债务**：谁拿走了邪契者，就连同它的"偿契"要求一起继承。宗主会在 3 天内发信"新的债务人"——这是故意的。

## 四、目标的下场

目标**一定失去**被夺的特性。另外：

| 阶 | 目标结果 |
|---|---|
| 一阶 | 「魂伤」10 天：意识 −10%，心情 −10，囚犯抵抗 / 意志 −30%（更好招募 / 奴役）。 |
| 二阶 | 「魂伤」30 天：意识 −20%，心情 −15；50% 失去一项兴趣（火焰降一档）。 |
| 三阶 | 「魂伤·重」60 天：意识 −30%，心灵敏感度 −30%；目标从此变成**空壳**：永久 `LP_Hollowed`（隐藏特性"空洞"——不会再随机得到强力特性，社交 −20）。 |
| 四阶 | **目标死亡**（灵魂被撕开）。尸体照常可以献祭给巫妖、给夺心魔吞噬（大脑完整）。 |

- 心情：目睹者心情 −6「目睹夺魂」（精神病态、嗜血者、邪恶阵营不扣）；全殖民地 −3「我们做了夺魂的事」5 天（同上例外）。没装 Ideology 也有，这两条是普通想法。
- 派系：目标所属派系非敌对时好感 −20（照原版摘器官的力度）；目标被释放回去时再 −10。
- 招募：魂伤期间招募成功后，新殖民者带"恨意"记忆（对主祭好感 −40，永久衰减很慢）。

## 五、主祭的限制和代价

1. **强力特性一个**（见 3.4）。
2. **夺来的特性最多两个**。记在 1.58.0 的隐藏记录 `Hediff_HeroRecord` 里（加一个字段 `stolen` 列表），第三次夺取必须先选一个旧的放弃。普通特性、强力特性都算在这两个里。特性名后面加灰色小字「（夺）」，悬停显示"夺自 某某"。
3. **排异期** 15 天（`LP_SoulRejection`）：特性已经生效，但期间主祭若精神崩溃，夺来的特性**脱落消失**。主祭心情 −8「这不是我的灵魂」（精神病态无此心情）。
4. **深渊腐化**：按阶 +5/+10/+20/+35（同深渊仪式），护阵者吃一半。腐化的种族倍率照 1.54.0（六臂蛇人免疫、提夫林 ×0.5、阿斯莫 ×2……）。
5. **阿斯莫**：照深渊仪式规则——腐化未到阴影阶段的阿斯莫拒绝主持。
6. **无暴力**的人不能主持二阶以上（同深渊仪式）。
7. **冷却**：同一个主祭每 7 天一次。
8. 薄弱度：每次仪式 +5/+10/+15/+25，失败 ×2（同深渊仪式），所以频繁夺魂会招来深渊事件。

## 六、变体：秽魂转嫁（把坏特性甩给囚犯）

同一个法阵，模式切到「转嫁」：主祭 = 被治疗的殖民者本人（或另一个主祭 + 该殖民者站在法阵上）。

- 能转嫁：原版负面特性（纵火狂、化学兴趣、懒惰程度、悲观、神经质负面端、丑陋、恶心、嗜酒……）、1.58.2 以后若做诅咒之力（兽化症等）也可以——**作为它的解除方法之一**。
- 不能转嫁：基因给的、性取向、背景特性。
- 一律按一阶算（85%、2 灵魂币、腐化 +3），目标只吃一阶魂伤，并**得到**那个坏特性。
- 失败不回流也不碎：坏特性留在原主身上，只扣祭品 + 主祭反噬（第七节小失败）。

这让夺魂仪式除了"偷强者"之外，日常也有用：抓来的囚犯可以当"垃圾桶"，代价是腐化和薄弱度。

## 七、失败、巫妖、夺心魔

### 7.1 失败三档（照 `AbyssRitual.Judge`）

| 结果 | 条件 | 发生什么 |
|---|---|---|
| 成功 | 掷出 ≤ 成功率 | 见上。 |
| **碎魂**（小失败） | 差距 < 20% | 特性被剥出来但**碎掉**：目标照样失去它、照样吃魂伤，主祭什么都没得到；主祭「魂火反噬」：昏迷 6 小时 + 腐化再 +一半。 |
| **附魂**（大失败） | 差距 ≥ 20% | 目标的灵魂碎片反咬主祭：主祭**得到目标身上最坏的一个负面特性**（没有负面特性就得到「魂伤」）；同时按阶召来一个**未束缚的敌对恶魔**（一阶劣魔群、二阶巴路古拉、三阶纳巴苏、四阶炎魔——就是深渊仪式的"召来但未束缚"），四阶大失败按原规则开裂口。目标没失去特性，但吃魂伤。 |

被打断（主祭倒地、征召、崩溃）按"附魂"处理，和深渊仪式一致。

### 7.2 巫妖（`LP_Altar` 副场 + 魂匣藏性）

- 巫妖当主祭：深渊法阵上照常 +5%（`LichBonus`）；腐化 ×0.5、没有"这不是我的灵魂"心情、没有排异期（亡灵的灵魂本来就在命匣里，不会排斥）。
- **巫妖仪式桌路线**：巫妖可以在自己的 `LP_Altar` 上做同样的夺魂（只限巫妖主祭、没有护阵者）。不用灵魂币和恶魔血，改为扣命匣献祭经验（一阶 / 二阶 / 三阶 / 四阶 = 当前等级需求的 10% / 25% / 50% / 100%），不吃腐化，不涨薄弱度。基础成功率比法阵低 10%。这样不碰深渊线的巫妖玩家也能用。
- **魂匣藏性**：巫妖夺来的特性可以选择"存进命匣"而不是装到自己身上。命匣可存 `1 + 命匣等级 / 5` 个特性（检视面板显示）。以后在命匣上点「赐予」，把存着的特性给一名**巫妖统御下的殖民者**（不是死灵造物）——仍遵守强力特性一个 / 夺来特性两个的上限、走一次 2 小时的引导、获得者吃排异期。这是巫妖作为"灵魂收藏家"的玩法，也是除了自愿传承外唯一能把特性给第三人的办法。
- 四阶目标死亡时，灵魂照常进入命匣（算一次献祭经验，和普通献祭一样）。
- 夺**巫妖本身**（命匣在同一个法阵上时）：只能夺不能留命，成功后命匣碎裂、巫妖真正死亡。界面黑字警告。

### 7.3 夺心魔与吞噬大脑

两件事**分开**，不互相替代：吞噬大脑给脑髓、不给特性；夺魂给特性、不给脑髓。联动只有三条：
- 夺心魔 / 半夺心魔当主祭，夺**心智类**特性（原版 意志坚定、神经质、乐观 / 悲观、快速学习、心灵敏感度、敏锐 等，名单写在 XML 里）成功率 +10%——它们本来就擅长从脑子里拿东西。
- 被夺过二阶以上特性的目标，之后被吞噬大脑时脑髓 ×0.7（"已经被剥过了"）。
- 吞噬大脑的目标（大脑缺失）当然不能再夺；四阶夺魂死掉的目标大脑完整，可以吞——先夺后吞是最"夺心魔"的顺序。

## 八、Ideology（可选）

不装 Ideology：仪式完整可用，奴隶选项不出现，心情用普通想法（第四节）。

装了 Ideology（放在 1.56.0 的 `Bridges/Ideology` 桥里，不碰主程序集逻辑）：
- 主程序集在仪式结束时抛事件，桥记成历史事件 `LP_HE_SoulReaped`（夺魂）、`LP_HE_SoulOffloaded`（转嫁）。
- 新议题 **「夺魂」`LP_Issue_SoulReaping`**，三档戒律：可憎（夺魂 −10，知道 −4）/ 可接受（无）/ 神圣（夺魂 +5，殖民地 7 天内做过 +2）。
- 1.56.0 已有模因的默认：**深渊之门 / 契约之律 / 永夜不朽** → 神圣；**主脑合一**（殖巢 NPC）→ 可接受；**九神 + 众神殿 / 晨主之光** → 可憎；**灰烬之誓** → 可憎（吉斯洋基憎恶任何吃灵魂的东西）。
- 文化里有"可憎"时，普通想法版本的"我们做了夺魂的事"不再出现（改由戒律负责），避免双扣。

## 九、以后可做（本批不做）

- **圣坛·自愿传承**：殖民者之间自愿转移特性（好感 ≥ 20、非精神病态），扣神眷 20/40/80，不吃腐化，不能传天命；神之勇士可在同神信徒之间传（80 神眷）。适合"老兵把『勇者』传给孩子"的故事。等 Peter 想要善良路线时再做。
- 敌人用夺魂：拉洛克 / 黑网据点里有"夺魂法阵"，被俘的殖民者可能被夺走特性（营救任务）。
- 魂匣藏性的特性也能当商品卖给黑网（灵魂黑市）。

## 十、我替 Peter 定下的决定

1. 放在**深渊法阵**上，复用 1.54.0 全套写法；巫妖另有仪式桌路线；不依赖 Ideology。
2. 只对**囚犯 / 奴隶**；倒地敌人先抓。外来者、亡灵（除带着命匣的巫妖）、儿童不行。
3. 能夺：原版 + 其他模组普通特性 + 1.51/1.58 强力特性 + Isekai 特性（默认开，设置可关）。不能夺：背景特性、传说事迹、神之勇士、按击杀得到的里程碑、性取向、基因给的特性。
4. 严格遵守**每人一个强力特性**；已有时必须明确挤掉旧的。夺来的特性每人最多两个。
5. 目标一定失去特性；一阶 / 二阶只受伤，三阶变空壳，**四阶（天命）目标死亡**。
6. 代价 = 灵魂币 / 恶魔血 / 神迹残片 + 深渊腐化 + 排异期 + 心情 + 薄弱度。不加新研究。
7. 失败：小失败特性碎掉，大失败主祭染上目标的坏特性并召来敌对恶魔。
8. 吞噬大脑和夺魂分开，只做三条小联动。
9. 不做 d20；成功率全部是平的百分比，沿用深渊仪式的公式。
