### 1. 排版
- 顺序：等级行 → 经验条 → 加点栏 → 六维（每行一项，后面 +1/+2 和当前效果）→ 部位生命 / 史诗恩赐 → 传奇属性点 → 专长 → 种族 / 天赋 / 半神 / 宿敌 / VPE / 里程碑。
- 灰色占位行：“暂无专长（可以用一次属性提升改选专长）”“传奇属性点在成为传奇冒险者后解锁”（传奇等级关闭时写明已关闭）；天赋没有时写“天赋：无”。
- Isekai 共存模式只把“部位生命”行换成灰色说明，其余内容和所有按钮都照常显示。

### 2. 经验
- 等级行右边：“经验 9.0k / 11.3k”（≥1000 写 k，一位小数）；下方本级进度条。20 级非传奇：“已满，需成为传奇冒险者” + 灰色满条。
- 悬停经验数字或经验条：击杀 / 协助、守住袭击、完成任务（都带这个人当前倍率下的示例数字）、六个 DND 里程碑（做过的打 ✓，拉洛克差事、神灵议会显示完成数）、击败传奇怪物、研习卷 / 云游导师、冒险者手册（超过 3 级显示“已超过”）、击杀里程碑（25…1000，做过的打 ✓；传奇另写 500/1000 各 +3 传奇属性点）、宿敌冠军，最后一行当前经验倍率（设置 × 凡人之志）。

### 3. 就地加点
- “可用属性点：N” = 剩余属性提升 × 2（百炼成钢 × 3）+ 拆剩的点。+1 永远有，点数 ≥ 2 时多一个 +2；超过上限的按钮灰掉，悬停显示加点后的效果（含种族亲和），点击立即 `Dirty()` 生效。
- 同一行：“改选专长（N）”“史诗恩赐（N）”（打开原窗口）和“自动加点”勾选框（同步设置 `adventurerAutoASI` 并保存；勾上时这个人剩下的点立即自动分配）。
- 传奇属性点每项 +1，余额 ≥ 5 时 +5；悬停看当前、下一点、投后效果。旧窗口、升级信件里的按钮都保留。

### 4. 熟练加值
- 每比 +2 高 1 点：近战命中 +2%（加在最终命中率上，原因同群嚎：命中率属性有曲线，前面加偏移会被压没）、射击精度 ×+1%（合进冒险者状态的系数）、VPE 职业强度 +0.02（原有）。只看等级，不乘“属性效果强度”，共存模式也生效；传奇怪物不算。
- 等级行“熟练加值 +N”悬停：上述三项的当前数值、下一次提升的等级、豁免和真龙交涉。
- 升级信件逐项：熟练加值变化及效果（或“仍为 +N，X 级升到 +N+1”）、属性提升与可用属性点（或“已自动分配”）、传奇属性点、VPE 路径点、部位生命成长（及当前合计）、史诗恩赐点、成为传奇、20 级封顶提示。
