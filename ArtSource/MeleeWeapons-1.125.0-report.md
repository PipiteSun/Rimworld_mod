# 1.125.0 近战武器后期化 报告

需求（Peter，经协调线程转达）：把 DND边缘大陆所有近战武器的数值调到 RimWorld 原版后期近战武器的强度。
版本：1.123.0 → **1.125.0**（1.124.0 已被同时进行的“UI 整理”线程占用，见 Source/LPUI.cs 和 ArtSource/backup-1.123.0-ui）。
备份：`ArtSource/backup-1.123.0-meleeweapons/`（14 个 Defs 文件 + MinotaurGithChecks.cs + About.xml + 使用说明.txt 的修改前原文）。

## 范围与原则

- 只改武器 ThingDef 的 `tools`（power / cooldownTime / armorPenetration），以及描述里写死的旧数字。**没有改任何 C# 伤害公式**（力量、职业、品质、种族加成照旧叠在上面）。
- C# 里写死的武器伤害检查过：矮人投掷锤的投掷伤害 = 锤头 tool 的 power × 品质/材料倍率（`ItemsRaceGear.HammerDamage`），会跟着变高；其余（诸神之祸对神 ×2、卡斯之剑对维克那 ×2、晨星对不死 ×2、龙杀手 ×1.5、火焰舌/霜寒之刃 +8 元素伤害、天穹之剑 25% 雷霆、风暴之矛 20% 落雷、复仇之剑 +15%）都是倍率或固定附加，没动。
- 保持每把武器原有的特色（钝 / 锐、重锤慢而狠、长剑三段攻击、快攻低伤）和原有的强弱顺序。**没有削弱任何武器**。
- 市值（MarketValue）没改，只调战斗数值。
- 不算近战武器、没动：法杖、枪械、弓的“枪托 / 弓身”近战（9 点钝击），炎魔火鞭（短程远程武器），闪电标枪（投掷）。

## 决定与说明

1. **档位来源**：`Source/ClassCasters.cs` 里给器械师门槛用的表把武器分成 Workshop（奥术工坊）和 Inscription（符文铭刻），直接照这个分档；没在表里的不可制作武器按来源归为传奇 / 圣物 / 传承 / 神器 / 契约。
2. **魔化兵器基底**（`LP_MagicBladeBase`）一次抬到铭刻档，火焰舌、霜寒之刃、龙杀手、守护者之剑、复仇之剑一起受益；**锐锋剑**是不能制作的传奇，改为单独覆盖 tools，略高于灵能单分子剑。
3. **复仇之剑**（诅咒物品）跟着基底到铭刻档，没有单独再调——它本来就是“拿了放不下”的诅咒物，+15% 近战伤害照旧。
4. **巨人武器**本来就按“大一号”设计，按原来和同档普通武器的比例浮在上面；熔核破城锤是精英禁卫武器，到 18.8，和神器同档。
5. **食人魔大棒**：新石器、手工制作点就能做（木头也行），只调到 ≈10（等离子剑档下沿），避免开局就拿到后期武器；体型不足仍 ×60%。
6. **制伏短棍**：非致命武器，伤害只决定“几下打晕”，只把间隔从 1.6 缩到 1.5、伤害 12/9 → 14/11，打晕得稍快一点（原来人类 3～4 下）。自检里用的是固定 12 点，不受影响。
7. **矮人投掷锤**：投掷伤害 = 锤头伤害 × 品质/材料倍率，16 → 23，投掷也一起变强（原设计就是“一次锤头伤害”）。
8. **传承武器**（黎明之誓、山之心）本身生成就是大师级，觉醒 / 升华还有 +15% / +15%，所以普通品质基准定在灵能武器同档（15.5～15.9），没有再往上加。
9. **敌人也会变强**：吉斯洋基（25% 带银剑）、寒冰魔（霜刺长枪）、食人魔打手（大棒）、霜巨人掠夺者、火巨人（熔炉重锤）、熔核禁卫拿的都是这些武器。这是“所有近战武器到后期档”的自然结果，没另加限制。
10. **描述同步**：写了具体数字或“××长剑的几倍”的描述都改了（天穹之矛、诸神之祸、独眼巨锤、霜巨人斧、风暴三叉戟、云巨人晨星锤、熔核破城锤、地狱钢叉），使用说明.txt 里对应的 11 处也同步（精确锚点编辑）。
11. **自检**：`MinotaurGithChecks.CheckSilverSword` 原来断言“银剑 tools 和钢长剑完全一样”，改为“每个部位伤害不低于钢长剑、间隔不更慢、最高一招更高、主攻穿甲 60%”。**这是 C# 改动，需要下一次 Build.ps1 编译后才生效**；在那之前用旧 DLL 跑 `-Only MinotaurGith` 会有这 1 条预期失败。本次没有编译（同时有 UI 线程在改 Source，编译会把别人没做完的改动一起打进去）。

自检第二处：`CheckSilverSword` 里“非吉斯洋基手里银剑 = 普通钢长剑”（实测剑刃伤害比）改为“= 钢长剑 × 剑刃 power 比（30/23）且没有灵能伤害”。实测 30.23 vs 23.18 = 1.304，正好是 30/23，说明武器数值本身生效正确。
