# 五色真龙身体重画报告（1028 美术热修）

需求：Peter 给的参考图（低伏的四足龙，翅膀收拢盖在背上，有角，粗黑轮廓，平涂加柔和暗面，多种配色），要求把“HAR龙”的贴图照这个风格重画。版本不变（仍是设备上的版本），这次只改贴图。

## 一、理解

“HAR龙”按 **五色真龙**（红、蓝、绿、黑、白）理解：模组里只有这几条龙是用 HAR 身体贴图画出来的（`Bridges/HAR/Textures/ChromaticDragons/<色>/Naked_Hulk_*.png`，整条龙连头一起画在身体贴图里）。力能龙裔是人形种族，不算在内。每条龙的配色就是它本身的颜色，没有另外加参考图里的青绿、紫色变体。

## 三、画法

- 姿态（第二版，看到参考图后重画；第一版是蹲坐的卡通龙，太粗短，已被覆盖）：修长的身体伏在地上，长颈从胸前弯起，头略低；翅膀收拢成长叶形盖在背上，翼骨画成浅色条纹（正面看两片翅膀伸向两侧后方，背面看两片翅膀在脊背上合拢）；尾巴绕到身前，贴着地面；前爪收在胸前；身上有少量浅色斑点。龙一直是这个伏地姿势，走路时也一样，跟参考图一致。
- 第三版（Peter 21:19 又给了冰霜、沙漠两组参考图，要的是身体圆、头小、像 RimWorld 的动物）：身体更高更圆；颈缩短加粗；头画在单独一层，缩到 0.84 倍再贴回颈端；翅膀下沿改成一个个蝙蝠翼的指尖；白龙尾尖换成羽状尾鳍。
- 第四版（Peter 21:25：“太棱角分明，不像 RimWorld 画风”）：所有多边形改成闭合的 Catmull-Rom 曲线；每块形状的遮罩先模糊、再取一半，把尖角磨圆、凹角填平；翼骨改成略弯的细条。
- 第五版（Peter 21:25：“不够有设计感”）：每种颜色有自己的特征（`STYLE` 表）。背脊的鳍从收拢的翅膀上沿露出来，尾巴外圈也有：红龙是一排大三角棘，蓝龙是短而密的刃鳍，绿龙是带鳍条的波浪背帆，黑龙是稀疏带钩的骨刺，白龙是羽毛簇。翼膜往下沿渐变成第二种颜色：红龙橙，蓝龙青，绿龙黄绿，黑龙紫，白龙冰白。花纹：红龙、黑龙是深色横带，蓝龙、绿龙是浅色斑点，白龙是淡蓝细纹。背面的脊棘颜色跟侧面的背鳍一致。
- 头：沿用 1.52.0 每种颜色的头型：红龙是后掠大角，蓝龙是鼻上独角加耳鳍，绿龙是头冠加侧鳍，黑龙是前伸弯角加露骨的吻，白龙是鬃冠加小角。
- 风格：粗黑轮廓（OW 2.4，原来是 2.2）、平涂；每一块右下有一条模糊的暗边，左上有一条淡的亮边，光从左上照过来。用的是低饱和调色，黑龙稍微偏紫，靠近参考图。
- 尺寸和位置：画布还是 256px，龙在画面中央；伏地后身体底边在大约 91–95% 高度（旧图的脚在 88–91%），所以游戏里的 drawSize / ScaleFor 缩放和偏移不用改。龙伏下后比旧图矮，大约占画面下面 2/3。

## 四、体型放大（Peter 21:15 要求，按 D&D 设定放大）

渲染缩放只有一处：`Source/ChromaticDragons.cs` 里的 `Dragons.RenderScale`，青年 / 成年 / 远古从 `{2.0, 2.8, 3.8}` 改成 **`{2.6, 3.8, 5.2}`**（大约 +30–37%）。龙伏下后，侧面身长大约是 3.6 / 5.2 / 7.2 格，对应 D&D 的大型 / 超大型 / 巨型，再加上颈和尾的长度。对比图：`ArtSource/Preview/ChromaticDragons-size-1028.png`。
