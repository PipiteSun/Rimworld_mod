# 1.93.0 部位生命升级不降（「为什么升级法师，部位生命下降了」）

## 结论：真实数值下降，不只是显示
旧公式 `Hediff_Adventurer.LevelGrowth(lv)` = 平均每级成长 × (lv − 1)，未分配职业点按 5%。法师 / 术士每级 4%，给法师加点会把一个 5% 换成 4%，平均值下降 → `PartFactor` 真的变小（显示和实际用的是同一个函数）。

截图（冒险者 3 级，法师 2 → 3，其他倍率 ≈ ×1.450 含体质）：
- 旧：加点前 (2×4% + 5%)/3×2 = 8.67% → +57.6%；加点后 3×4%/3×2 = 8% → +56.6%（−1.0%）。
- 新：加点前 2×4% + 1×4% − 4% = 8% → +56.6%；加点后 3×4% − 4% = 8% → +56.6%（持平）。
  （读档后这个人在加点前就会显示 +56.6%：未分配点从 5% 改成 4%。）

## 新公式
等级成长 = Σ 各职业等级 × 该职业每级成长 + 未分配等级 × 4% − 4%（最低 0；冒险者等级超过 20 按 20 算）。
- 加任何职业点：+（职业每级 − 4%）≥ 0（法师 / 术士 0，d8 职业 +1%，战士 / 圣武士 / 游侠 +2%，野蛮人 +3%）。
- 冒险者升级：+4%（新的未分配等级）；21–40 传奇等级不变（不降）。
- 职业每级成长不变：野蛮人 7%，战士 / 圣武士 / 游侠 6%，法师 / 术士 4%，其他 5%；体质倍率不变。
- 影响：纯法师 / 术士与旧值相同；其他职业全部分配时多出“职业 − 4%”一级（例如 6 级纯战士 +30% → +32%，再乘体质）；未分配的等级 5% → 4%。NPC 走同一函数。
