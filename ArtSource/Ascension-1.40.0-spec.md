# 成神任务线实现要求（1.40.0）

范围：4 条成神任务链（圣徒、半神巫妖、泰坦觉醒、篡火者）+ 接入耐瑟瑞尔的奥术半神，统一的半神状态、神职能力、神力、神性等级升级、名额上限、升入神域结局。不做会走路的神本体（化身）、不做动荡之年。神只通过信件、凡人仆从（勇士、末日卫士）和神明附体首领出现。本模组只读神眷值和圣坛，不改信仰的 def；加减神眷只用 FaithUtility.AddFavor。神职不加进 LP_DeityDef 的 C# 类，用本版的 DefModExtension LP_PortfolioExtension { portfolio }，通过 Patches/Ascension.xml 挂到 11 位神上。魔网神选不存在，“奥术半神与魔网神选敌视”不做。

## 一、统一框架

1. 任务追踪：WorldComponent LP_AscensionTracker，每名走成神路的殖民者一条 AscensionProgress { pawn, path, stage, counters, patronGod, stageStartTick, done }。一人同时只走一条路；多人可同时在走，名额只在升神那一刻检查。走路的人死了进度清空（巫妖能复生，半神巫妖路不清空）；离开殖民地/被俘超过 15 天清空。界面：符合开启条件或正在走路的殖民者有按钮“成神之路”，打开小窗口：路线名、当前试炼、完成条件、进度条、下一步提示；开启时“踏上此路”按钮（二次确认说明代价）。每完成一步发信件。

2. 研究“神格学”：前置 = 信仰的第一项研究（没有就无前置），3000 点，中世纪。研究完成前没有“成神之路”按钮，升神仪式也要求它。

3. 神性火花 LP_DivineSpark：不能出售（市场价 0），不腐坏，不可燃，CompDivineSpark 记神职和来源路线。地图上有火花：所有殖民者心情 +4“神性的光辉”（一张图只算一次）。只能被产出它的殖民者吸收（篡火者火花除外）。

4. 升神仪式：在圣坛 LP_FaithAltar（ExtraGizmos 挂按钮；半神巫妖路改为命匣旁）。主祭带火花引导 12 小时（可打断，不消耗火花）。期间“神性震荡”天象：心灵法术冷却 ×1.5。成功率：圣徒、半神巫妖、泰坦 100%；篡火者见 E。名额：现有半神数 ≥ 设置上限（默认 1）时按钮灰掉并说明。升入神域的不占名额。

5. 半神 hediff LP_Demigod，任何种族可叠加，HediffComp_Demigod { level 1～5, portfolio, divinePower, lastTrialTick }，阶段名：新生神祇/次级神祇/中等神祇/高等神祇/神域之主。
- 1 级：不老（Harmony 拦生理年龄增长，参考已有不老实现）；饥饿 ×0.3；免疫疾病；心灵敏感度 +0.2（每级 +0.05）；受到伤害 ×0.95（每级再 ×0.95）；精神崩溃阈值 -10%；神力上限 100（每级 +50）；神职能力强度 ×1.0（每级 +0.25）。不给免控、不给凡铁难伤。
- 神职给 2 个主动 + 1 个被动（第三节），主动用原版 AbilityDef（不依赖 VPE），消耗神力。
- 神力每天结算 = 2 + 0.5 × 守护神是该神的信徒殖民者数（LP_Devotee）+ 0.2 × 其他对半神好感 ≥ 20 的殖民者数。显示在 hediff 提示和一个神力条 gizmo（金色，照巫妖精神力条画法）。
- 僭越：每天除守护神外其余每位神神眷 -0.1。篡火者路：被篡的神神眷固定 -100（每天重设）。
- MiracleCost 后缀：半神施放其守护神的神术消耗 ×0.5。

6. 神灵议会（升级）：神力满、距上次 ≥ 30 天、等级 < 5 时出现按钮“接受众神的试炼”。1 天后来“众神的勇士”袭击：派系 = 与半神神职对立神（LP_DeityDef.enemies）的那个派系，找不到用塞伊远征军；点数 = max(殖民地袭击点数, 2000 + 1000×等级) × 难度倍率；首领必带 1.28.0 神明附体（用现有附体 API）。Lord 结束时半神整个试炼期间没倒地 → 等级 +1，信件，全员心情 +8“新神崛起”10 天；倒过地 → 神力清零，30 天冷却，等级不降。Isekai 档位正常随机。

7. 升入神域：等级 5 时按钮“升入神域”（二次确认）。半神光柱离开地图（世界 pawn，标记已升神），释放名额。殖民地永久获得该神职“神域赐福”（第三节最后一列，世界组件记录，所有玩家地图生效），全员心情 +15“我们的神在看着我们”30 天，之后永久 +3。

8. 设置：设置页新段“成神”，放在信仰段下面：开关（默认开）；半神名额上限 1～3（默认 1）；试炼难度倍率 0.5～2.0（默认 1.0，作用于所有任务链袭击点数和神灵议会）。

## 二、四条任务链（袭击都乘难度倍率，用原版 RaidEnemy 参数生成，信件说明这是试炼）

### A. 圣徒之路（神选者 → 圣徒 → 半神）
开启：有 LP_Chosen（神 G）且 G 神眷 ≥ 60（无神者不行）。
- 试炼一 虔信：15 天内在圣坛祈祷/冥想累计 24 小时，期间心情一直 ≥ 30%（掉下去重置）。
- 试炼二 奉献：在圣坛献 5 个神迹残片 + 市场价合计 ≥ 3000 的物品（弹窗选物品，一次性消耗）。
- 试炼三 证道：“异端勇者”袭击，G 的对立神派系，首领带神明附体，点数 ≥ 2500；该神选者参战且活着，首领死亡或被俘。
- 中间奖励：特性 圣徒 LP_Saint（单级，commonality 0）：心灵敏感度 +0.15、社交 +2、G 神眷每天 +0.2；装 VPE 时神恩强度 +0.15。物品 圣徒圣印 LP_SaintSeal（LP_Accessory 层，不渲染，绑定本人）：心灵敏感度 +0.1、神职能力冷却 ×0.8、G 神眷获得 ×1.25。G 神眷 +20。
- 终试 圣火降临：成为圣徒满 30 天且 G 神眷 ≥ 90 → 事件“神性火花坠落”（空投舱效果改色）落在圣徒附近，2 天内 3 波“夺火者”：塞伊远征军 → 吉斯洋基（用 1.20.0 吉斯洋基生成）→ G 对立神派系，点数 × 1.0/1.2/1.5。三波打完前仪式按钮灰。火花神职 = G 的神职。

### B. 半神巫妖之路（巫妖，命匣实际等级 ≥ 20）
- 试炼一 万魂：开路后用“汲取灵魂”献祭 20 具完整人形尸体（只数开路后的）。
- 试炼二 抗拒审判：新隐藏派系 LP_KelemvorChurch（hidden，永久敌对，人形）的末日卫士 PawnKind LP_Doomguide，3 天 3 波，点数 × 0.8/1.0/1.3，Lord 目标 = 命匣（照 LordJob_AssaultThings）。末日卫士：灰袍（现有袍子染灰）+ 现有法杖/长剑，LP_Radiant 近战，对亡灵（巫妖、骷髅、死灵造物）×1.5。第三波首领“凯兰沃的审判者”带“冻结复生”光环（半径 15，巫妖/巨魔复生计时暂停），死后掉落火花（神职 不死）。命匣没被毁 = 通过。
- 试炼三 夺神：在命匣旁升神仪式，期间来一波吉斯洋基。
- 开路时凯兰沃神眷 -50；成功后固定 -100。
- 奖励：LP_Demigod 神职 不死；命匣 → 神龛（标记 + 贴图 Phylactery_Shrine，原图加金光和神纹）：复生 3 天 → 1 天、命匣生命 ×2、复生时神力 ≥ 50 则扣 50 立即复生；物品 永夜冠冕 LP_EternalNightCrown（饰品层，绑定）：精神力上限 +30%、死灵造物统御容量 +4、神职能力伤害 +15%；吉斯洋基好感永久 -50（“巫妖女王的信徒”心情加成失效）。

### C. 泰坦觉醒（泰坦异种型，成年）
父神：坠落的神裔剧本若存了就用，否则开路时从 9 位可信奉神去掉班恩、莎尔后的 7 位中随机；父神神眷 +30（一次）。
- 试炼一 父神之誓：父神神职事迹计数（下表）。
- 试炼二 巨人之战：巨人王 + 氏族挑战（父神苏尔特 → 霜巨人；否则余烬氏族火巨人王 + 火巨人），点数 ≥ 3000；泰坦本人对巨人王造成 ≥ 30% 伤害，巨人王死或被俘。
- 试炼三 天穹之门：室外站 6 小时（可打断重来），期间“神怒风暴”天象 + 3 波位面生物（1.28.0 传送门四位面生物表随机一个）。
- 神职事迹表（篡火者复用）：黎明 救治倒地者（TendPatient 完成）15；正义 俘获敌人 5；风暴 雨/雷暴天杀敌 15；野性 驯服动物或杀狂暴动物 合计 10；火焰 火焰伤害杀敌 15；死亡 入葬或摧毁亡灵 合计 12；魔法 成功施放消耗精神力或神眷的能力 30；黑暗 夜间（22～5 点）杀敌 15。
- 奖励：异种型 泰坦 → 觉醒泰坦 LP_AwakenedTitan（泰坦全部基因 + 新基因 LP_DivineBlood：头顶淡金光环叠加层，心灵敏感度 +0.2，体型同泰坦 2.5），只替换泰坦异种型，保留其它基因；孩子是普通泰坦（LP_DivineBlood 不遗传）。LP_Demigod 神职 = 父神神职，试炼三完成直接升神，不需要火花（名额满就停在“等待名额”）。物品 天穹之矛 LP_SkySpear：近战长矛，绑定，伤害 = 普通长矛 × 1.6，附带父神神职伤害（黎明/正义 LP_Radiant，风暴 电击+小眩晕，野性 流血，火焰 燃烧，其它 LP_Radiant），不乘心灵敏感度（走 Isekai 和品质）。

### D. 奥术飞升（接入）
订阅 NetherilAscension.ArcaneDemigodGranted，读档时用 IsArcaneDemigod 补检；识别到就额外加 LP_Demigod（神职 奥术，不发本版能力），神力/议会/升入神域都生效，奥术半神原效果不动，占名额。

### E. 篡火者之路（黄昏之年进行中，任何殖民者）
开启：黄昏之年期间殖民者击杀或俘获一名神明附体袭击首领，自动开路并发信件。
- 试炼一 沾血：同一位神 X 的神明附体首领 3 名（不同神分开计数，先到 3 的为准）。第一次计数后得特性 弑神者 LP_Godslayer（单级，commonality 0）：对神力灌注者/神明附体/半神伤害 ×1.3，被神明附体首领技能命中效果 ×0.7。第 3 名首领死时掉落“篡夺的神性火花”（神职 = X，任何殖民者可吸收）。
- 试炼二 事迹：X 神职事迹（暴政/心灵/不死/奥术没有表内事迹的，改为击杀神力灌注者 10 名）。完成后才能开仪式。
- 成功率 = 50% + (心灵敏感度 - 1) × 50% + 每献 1 个神迹残片 +8%（最多 5 个），弑神者本人 +10%，上限 95%。失败：主祭死亡（尸体完整），火花碎成 5 个神迹残片。成功：LP_Demigod 神职 = X；X 神眷固定 -100，X 派系袭击频率 ×1.5（永久）；物品 诸神之祸 LP_Godsbane：近战长剑，绑定，对灌注者/附体/半神伤害 ×2，其余同精工长剑 × 1.3。
- 黄昏之年结束时计数保留到下次。

## 三、神职与能力
