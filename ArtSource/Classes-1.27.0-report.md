# DND边缘大陆 1.27.0：DND 职业路径（VPE 联动）报告

日期：2026-10-25。基于 1.26.0。备份：ArtSource/backup-1.26.0（About.xml、使用说明.txt、LoadFolders.xml、Source/Build.ps1、Source/Test.ps1、Source/Checks.cs 的改动前原件）。
设计说明：ArtSource/Classes-1.27.0-spec.md。图标预览：ArtSource/Classes-1.27.0-preview.png。

## 做了什么
- 只在启用 Vanilla Psycasts Expanded（vanillaexpanded.vpsycastse）时由 LoadFolders 加载 `Bridges/VPE`；主程序集不引用 VEF.dll / VanillaPsycastsExpanded.dll。没装 VPE 时一个 Def 都不加载（Core 测试里有一条专门检查）。
- 灵能页签新增分页 **DND职业**，三条路径：**战士**（格斗）、**法师**（智识）、**牧师**（社交）。
  - 解锁路径：VPE 原条件（心灵链接 + 1 点）+ 职业技能 ≥ 6；锁住时显示“需要格斗 6 级”等。
  - 学能力：VPE 原条件（前置 + 1 点）+ 本环技能要求 1/2/3/4/5 环 = 6/9/12/15/18 级；神经成型器同样受限。学会后技能下降不失去能力。
  - 第 5 环前置是“第 4 环任一”（VPE 的前置本身就是“任一满足”）。
- 新属性 **战技强度 / 奥术强度 / 神恩强度** = 0.5 + 技能/20（6 级 80%，10 级 100%，20 级 150%），显示在角色属性里。能力的伤害、治疗、持续时间、半径、距离乘它；不再乘心灵敏感度。
- 经验：已解锁某条路径的人，该路径技能每 100 点技能经验 → 1 点 VPE 灵能经验，每人每天 50 上限；神经成型器等直接给的经验不算。
- 新物品 **冒险者手册**（炼金桌，布 20 + 金 10，研究“DND炼金术”；奇物商队/轨道商人 0～1 本，约 800 银）：没有心灵链接且任一职业技能 ≥ 8 → 1 级心灵链接 + 免费解锁对应路径（技能最高的）；已有链接的人 → 解锁一条新路径（技能 ≥ 6，不花点）。一次性。
- 新伤害类型：奥术力（钝器类护甲，穿甲 0.3）、闪电（热类护甲，穿甲 0.5）、神圣（热类护甲，对亡灵/邪魔/夺心魔 ×2）。
