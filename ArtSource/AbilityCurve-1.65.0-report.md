# 1.65.0 六维倍率曲线

曲线（`Adventurer.Curve`，D&D 3.5 负重表）：10 = ×1；<10 = 属性/10；11–19 = 1.15/1.3/1.5/1.75/2/2.3/2.6/3/3.5；之后每 +10 ×4（20 = 4，24 = 7，30 = 16）。

`Hediff_Adventurer.AMult(a)`：曲线值，种族亲和 / 天赋只乘高出 1 的部分。`Fx(a,k,s) = 1 + (AMult^k − 1) × s`（s = 属性效果强度）。

| 属性 | 整条曲线 M | √M | M^¼ / M^⅕ |
|---|---|---|---|
| 力量 | 近战伤害、负重 | 格斗学习 | |
| 敏捷 | | 近战闪避 +10×(√M−1)、射击学习 | 射击精度 ×M^¼、瞄准时间 ÷M^¼、移速 ×M^⅕ |
| 体质 | 部位生命（×(1+1%/级)，体质 <10 不减少） | 免疫、疼痛休克阈值 +10%×(√M−1) | |

2026-10-29 补充（对齐 Isekai 六维对象）：力 采矿 ×M；敏 近战命中 ×M^¼、商队速度 ×M^⅕；体 伤口愈合 ×√M、休息 ×M^¼、毒抗 +10%×(√M−1)、利器/钝器/高温护甲 +5%×(√M−1)；智 工作速度 ×M^¼、黑客 ×√M；感 手术 / 冥想 / 动物采集 / 心灵热量恢复 ×√M、热量上限 ×M^¼、崩溃阈值 −4%×(√M−1)；驯服移到魅力，魅力加谈判 / 结缘 / 逮捕 ×√M。不做：远程伤害、武器射程、制造品质、经验获取、衰老（Isekai 自有机制，本模组没有对应属性）。测试 `-Only Adventurer,Exalted` 166、`-Only HeroTraits` 25、`-VPE -Only Adventurer` 19 通过。

VPE 职业强度：0.25×(√M−1) + 0.02×(熟练−2)。检定 / 豁免 / 专长门槛不变（仍用调整值）。

平衡：传奇单位（`Legendary.Is`）不吃六维效果；`Dragons.ScoreHealth` = 1 + 2×属性效果强度，真龙与传奇怪生命 ×3，龙平衡检查回到 60–150 秒。

测试：`-Only Adventurer,Exalted` 166 PASS；`-VPE -Only Adventurer` 19 PASS；`-Only ChromaticDragons` 23 PASS（吐息 / 威仪两条随机失败，旧 DLL 同样出现）；`-Only LegendaryMonsters` 第 4 条死亡骑士化灰在旧 DLL 上也失败（既有问题）。
