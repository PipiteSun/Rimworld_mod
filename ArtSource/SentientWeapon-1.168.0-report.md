# 1.168.0 人格武器 报告（2026-11-16）

需求（Peter，经协调者转达）：DND 那种有人格的武器（智能物品 / 原版人格武器），能通过附魔获得。细节由我决定。

## 做了什么
- 附魔台「附魔强化」窗口：选中武器时，中栏下面新增「人格」一节（唤醒人格 / 重塑人格 / 解除羁绊）。
- 唤醒条件：武器强化到 +5 以上；工匠智识 10（同高阶强化工作单）；每次 6 精金 + 20 黄金；成功率 60% + 技能加成（同附魔强化，最多 +18%）+ 奥术聚能石 5%；失败只损失材料。
- 唤醒后：武器得到随机名字（显示「名字」+N 武器）和 8 种人格之一：

| 人格 | 初醒 | 苏醒（共鸣 30） | 升华（共鸣 100） |
|---|---|---|---|
| 嗜血 | 近战伤害 ×1.1，近战命中 +2 | ×1.2，+4 | ×1.3，+6 |
| 守护 | 受到伤害 ×0.92，痛觉休克阈值 +5% | ×0.85，+10% | ×0.78，+15% |
| 智者 | 学习 +15%，研究 +10% | +30%，+20% | +45%，+30% |
| 猎手 | 射击精度 +3，瞄准时间 ×0.92 | +5，×0.85 | +8，×0.78 |
| 迅影 | 移速 +0.3，近战闪避 +4 | +0.5，+8 | +0.8，+12 |
| 狂怒 | 近战冷却 ×0.92，近战命中 +1 | ×0.85，+2 | ×0.78，+3 |
| 静谧 | 精神崩溃阈值 -3%，精神抗性 +10% | -6%，+20% | -9%，+30% |
| 王者 | 社交影响 +10%，谈判 +10% | +20% | +30% |

- 羁绊：第一个装备它的殖民者自动结下羁绊（每人一把）；之后只有羁绊者能装备。羁绊者身上挂人格状态（健康页可见），拿着时生效并有心情 +3/+5/+7；没拿着是「分离」阶段，无加成、不扣心情。
- 共鸣：羁绊者拿着它击杀 +1（人形 +2），手持每天 +1。
- 重塑：同材料和成功率，换成另一种人格，共鸣保留。解除羁绊：羁绊者心情 -4（3 天），武器可重新结羁绊。羁绊者死亡时武器自动空出来。
