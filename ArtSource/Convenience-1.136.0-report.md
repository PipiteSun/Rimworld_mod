## 1. 施法自动化与资源条
- 先查了现有的 1.84.0 自动施放：按钮左上角勾选框 = 征召待命或战斗中自动施放（ClassData.autocast），右键菜单也能切换。保留不变，当作「征召时自动施放」。
- 新增：按钮右上角齿轮（有设置时变金色）→ 窗口 Dialog_AutoCast：征召时开关、「未征召时自动施放」（只给非敌对能力，即治疗 / 增益 / 防御）、「资源低于 X% 不自动用」（0～90%，10% 一档）。按人按能力存在 ClassData.autoModes。
- 未征召时自动施放的条件：醒着、不在床上、不在精神崩溃、没被击晕、当前不是玩家指派的工作；选目标沿用 NPC 施法逻辑（治疗先救倒地 / 受伤的友军）。
- 资源门槛按这个能力实际扣的资源算（施放职业的资源；湖印算湖息；游侠 / 器械师算法术能量）。
- 头像资源条：补丁 ColonistBarColonistDrawer.DrawColonist，在头像底部画 4 像素的条；主资源 = 等级最高、有资源的职业的资源，没有就法术能量，再没有就湖息；悬停显示数值。每个人 30 帧算一次（界面线程）。设置「冒险者」分组「殖民者头像资源条」可关。

## 2. 怪物图鉴
- 记录对象：本模组（LP_）的非人形生物，以及传奇单位（Legendary.Is，含可能是 HAR 人形的贝希尔等）和真龙；召唤物 / 灵体不算。
- 击杀：玩家阵营的人或炮台打死才计数；观察：每小时扫一遍殖民地地图和有殖民者的地图上没被迷雾挡住的这类生物，记下名字。
- 分级：1 只简介（种族描述），3 只弱点与抗性（护甲三项、可燃性、机械体提示、体型 / 战斗力 / 移速），10 只常见掉落（肉、皮、屠宰产物、死后掉落），25 只传说（一段固定格式的传说文字）并且殖民地对这种生物伤害 +5%。达到 3 / 10 / 25 时发一条消息。
- 主界面按钮「怪物图鉴」（MainButtonDef LP_Bestiary）：全部 / 怪物 / 野兽 / 传奇兽 / 真龙 筛选，左栏列表（没击杀过的图标灰显），右栏按级别展开、未解锁的写还差几只。存档保存（GameComponent_Bestiary）。

## 3. DND 角色卡
- 「DND 角色卡」检视分页挂到所有人形种族（有冒险者等级时显示），样式照 1.124.0（标题、金色区块标题条、两列、可滚动、悬停看说明）。
- 内容：冒险者等级（20 级以上写传奇等级）、熟练加值；六维（属性值、调整值，悬停看基础值和效果调整值）；职业（等级、子职业和分支选择，悬停看职业说明）、传奇职业能力；专长、起源专长、史诗恩赐；调谐位（DndImplants）；信仰（虔信的神，否则意识形态）；秘传槽与已学秘传、湖印槽与湖印、湖息；各职业强度（悬停是原版属性说明，即各 StatPart 的分项来源）和职业资源（悬停是资源公式）。

## 决定与偏差
- 「开关放在按钮角上小图标或右键」：征召开关仍是左上角勾和右键菜单（原有），新增的两项放在右上角齿轮打开的窗口里（没用浮动菜单）。
- 「治疗 / 增益 / 防御类」用「不是敌对能力」（AbilityDef.hostile = false）来判断。
- 图鉴的「传说」文字是统一模板，没有给每种生物单独写传说；「观察过」按每小时扫描地图实现。
- 图鉴里「野兽 / 怪物」的分法：6 种荒野魔物（锈蚀怪、凝胶怪、蛇怪、蝎尾狮、掘地兽、腐肉爬行者）和非动物算怪物，其余动物算野兽；名字带 Dragon 的算真龙，传奇单位算传奇兽。
- 资源条只显示一种主资源（多职业时取等级最高的那个）。
