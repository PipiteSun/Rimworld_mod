# 1.52.0 热修：设置窗口可滚动，冒险者等分组可见

## 问题
模组设置窗口（DND边缘大陆）只显示到左栏“上古脑召唤”、右栏“六臂蛇人 副手追加伤害”，没有滚动条；派系、野兽、事件、五色龙、枪械、流浆人、信仰、成神、冒险者（含“Isekai 共存模式”“种族亲和”“敌人冒险者等级”等）整组看不见。

## 原因
1.31.0 起设置已经放在滚动视图里，但两栏共用一个 `Listing_Standard`。左栏内容一超过列表矩形高度，`Listing_Standard` 就会自动换到下一栏，所以截图里的“右栏”其实是左栏的后半段（物品…六臂蛇人），第三、四栏画到了窗口右边外面。滚动高度又是按换栏后那一栏的 `CurHeight` 量的，量出来很短，于是也不出现滚动条。

## 修改（Source/Core.cs）
- 两栏各用一个独立的 `Listing_Standard`，高度 100000（不会自动换栏），量出两栏的真实高度给滚动视图。
- 分组改成两张表 `LichMod.SettingsLeft` / `SettingsRight`（名称 + 绘制方法），每组画一次，并记下起点（`SettingsAnchor`）。
- 窗口顶部加一排跳转按钮（15 个分组各一个，按窗口宽度自动换行），点按钮直接滚到对应分组。
- 左栏：命匣等 → 物品 → 神裔 → 巨人 → 背景特性 → 六臂蛇人 → 流浆人 → 信仰 → 成神
- 右栏：**冒险者** → 派系 → 野兽 → 事件 → 五色龙 → 枪械
- “冒险者”分组移到右栏最上面，“Isekai 共存模式”开关就在这一组里；顶部第一个按钮也是“冒险者”。
- 设置的保存键和各分组内容不变，旧设置照常读取。
