# 1.184.0 DND 生物按挑战等级（CR）定级

Peter（经协调线程，2026-11-19）：DND 野兽 / 怪物太弱，希望 CR N 的生物和 N 级冒险者强度相当（血量 = 原版 × 等级成长 × 体质 ×…）。

## 规则
- 对象：显示「挑战等级 CR」的 DND 生物 —— defName 以 LP_ 开头的非人形动物（野性等级本来就排除传奇怪物、五色真龙、虫族、异象、死灵造物 / 召唤物）。
- CR = 战斗力 ÷25 四舍五入，限 1～30（与检视面板上显示的 CR 一致，Epic.CR）。
- 野性等级下限 = CR：野外刷新、狂暴兽群、敌对组都先取 max(原规则等级, CR)，再加远古 +5、首领 +3。驯服后也保留（成长上限至少为 CR）。
- 野性等级本来就套冒险者公式：部位生命 = 原版 × 等级成长（每级 +5%，到 20 级）× 虚拟体质（1 + 15% × 调整值），近战伤害 × (1 + 10% × 虚拟力量调整值)，虚拟力量 / 体质 1 级 10、20 级 20、之后每级 +0.4。所以 CR N 生物 = N 级（5% 生命骰、六维随等级涨）的冒险者。
- 旧存档：读档后地图上低于 CR 的 DND 生物补到 CR（经验清零）。
- 塔拉斯克（战斗力 3000，CR 30）不加：它的外皮已按威胁点数缩放，叠加后几乎打不动。
- 设置「野兽」组新增开关「DND 生物按挑战等级定级」（默认开）。
