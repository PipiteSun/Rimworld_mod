# 魔法饰品构思（DND + 战锤40K）

2026-10-24 · 只是构思，还没有实现。写作时参照 DND边缘大陆 1.23.2 和刚下载的珠宝（Jewelry）模组。

**和以前文档的分工**：《DND物品构思二》第六、七节已经列过一批饰品：食人魔之力手套、接箭手套、鹰眼、伤口闭合护符、防探测护符、再生戒指、法术转向戒指、自由行动戒指、传心头盔、龙鳞护符，以及支配水晶、圣徽、施法焦点三件派系掉落。这里**不再重复它们**，只写新的。

---

## 一、先定三条规则（影响后面所有饰品）

### 1. 两枚戒指

DND 里一个人可以戴两枚戒指。现在的魔法戒指只能戴右手，一次一枚。建议改成**左右手各一枚**：

- 戒指可以戴在任意一只手上
- 同名戒指不叠加（不能戴两枚抗火戒指）
- 左手要是已经拿着矮人符文盾，也不影响戴戒指，因为盾在盾牌层

这样新戒指才有位置，不然所有戒指都在抢同一个格子。

### 2. 诅咒饰品

DND 有诅咒物品，40K 有混沌信物，正好合并成一个机制：

- 戴上以后**脱不下来**，只能用“解除诅咒卷轴”或者截肢解除
- 效果很强，但代价也大
- 未鉴定时不知道是诅咒物品：描述里只写“？”，需要“识破卷轴”或者让知识死灵研究一天才显示真实效果
- 新增卷轴：**解除诅咒卷轴**（教会牧师有售，也能由巫妖抄写）

### 3. 和珠宝的联动：附魔首饰（可选，珠宝启用时才加载）

珠宝的首饰可以在炼金桌上附魔，变成魔法首饰。**宝石种类决定效果方向**：

| 宝石 | 附魔方向 | 例子 |
|---|---|---|
| 红宝石 | 火 | 红宝石戒指 → 抗火戒指 |
| 蓝宝石 | 寒 | 蓝宝石戒指 → 抗寒戒指 |
| 翡翠 | 酸 / 自然 | 翡翠戒指 → 抗酸戒指 |
| 钻石 | 心灵 / 力场 | 钻石戒指 → 心灵抗性戒指、护盾胸针 |

- 附魔以后不再是珠宝层的首饰，而是变成我们饰品层的魔法饰品，避免同一件东西两头算
- 没装珠宝时，魔法饰品照旧用现有配方，不受影响
- 顺便把我们饰品层的标签从“饰品”改成“奇物”，和珠宝的“饰品”区分开

### 混沌印记（四种诅咒饰品）

都是“戴上脱不下”的诅咒饰品，效果很强，副作用也很明显：

| 印记 | 收益 | 代价 |
|---|---|---|
| **鲜血印记**（恐虐） | 近战伤害+30%、疼痛阈值+20% | 3天不打架就会陷入“嗜血”心情，越来越差，直到发狂 |
| **腐朽印记**（纳垢） | 免疫疾病和毒素，受伤流血-50% | 美观-3，身边的人心情-2，食物腐烂得更快 |
| **万变印记**（奸奇） | 心灵敏感度+40%、研究速度+20% | 每天随机一个小怪事：技能热情互换、头发变色、或者短暂眩晕 |
| **欢愉印记**（色孽） | 移速+15%，娱乐需求涨得慢一半 | 心情上限压低；娱乐不足时会去做“出格的事”（随机社交冲突） |

巫妖戴印记没有副作用，代价是同盟好感-30。这能让“邪恶路线”的巫妖开局多一种玩法。

## 四、建议的第一批（约10件）

挑和现有系统挂钩最紧、实现最简单的：

1. 先做规则：**两枚戒指**、**饰品层改名“奇物”**
2. DND：守护戒指、适应项链、护盾胸针、圣甲虫护符、夜视护目镜（全是“数值+少量判定”，半天能做完）
3. 40K：圣光冠环、魂石、灵能兜帽（分别对应“挡近战”“巫妖灵魂”“克夺心魔”，都是新玩法）
4. 珠宝联动：附魔首饰（只在珠宝启用时加载）

第二批再做：储法戒指、护佑誓约戒指、火球项链、复苏核心、诅咒机制和四种混沌印记。诅咒机制要动卷轴和鉴定，工作量最大，适合单独出一个版本。

## 五、要你定的事

1. **两枚戒指**：同意吗？还是保持一次一枚？
2. **40K 内容**：只取点子、改成费伦设定（本文默认），还是直接用 40K 原名、以后做 RimDark 桥接？
3. **诅咒饰品**：要不要做？“戴上脱不下”对一些玩家很烦，可以加一个设置开关
4. **魂石复活**：保留技能和记忆复活，会不会和巫妖的“唯一不死”定位冲突？可以改成只能复活成知识死灵
5. **圣光冠环**每天挡10次是否太强？备选：每天5次，或者只挡近战
6. **附魔首饰**：附魔后变成我们的魔法饰品（本文默认），还是保留珠宝首饰的属性、再叠加魔法效果？
