## 一、契约系统（`Source/Pacts.cs`）

### 1.1 宗主定义 `LP_PatronDef`（新 Def 类型，`Defs/Pact_Patrons.xml`）

| 字段 | 说明 |
|---|---|
| `plane` | 用 1.54.0 的位面枚举（Hells / Feywild） |
| `term` | `Year`（一年）/ `Life`（终身）/ `Soul`（灵魂：签约人得到 1.54.0 的灵魂抵押标记，死后不能复活、尸体消失） |
| `boons` | 恩赐列表（三选一），每个是 `LP_PactBoon`（`label`、`description`、`workerClass` + 参数） |
| `visibleClauses` | 可见代价列表（`LP_PactClause`：`kind` + 参数） |
| `hiddenClausePool` | 隐藏条款池，签约时抽 `hiddenCount` 条 |
| `demandInterval` | 偿契周期（天，IntRange） |
| `demands` | 偿契要求池（每次抽一条） |
| `reviewDC` | 审阅 DC |
| `negotiable` | 能否谈判（只有九狱） |
| `mutation` | 每季换一条可见代价的概率（妖精 0.2，九狱 0） |
| `taintOnSign` | 签约时签约人腐化（九狱 +10%，妖精 0） |

### 1.2 契约数据

`GameComponent_Pacts` 存所有契约（`List<Pact>`，可存档）。`Pact`：签约人、宗主、所选恩赐、条款列表（每条带 `revealed`）、债务（0～3）、下一次偿契时间、当前偿契要求和截止时间、签约时间、到期时间（一年契约）、状态。

一个人同时最多 **1 份契约**；一个殖民地同时最多 `1 + 殖民地最高冒险者等级 / 8` 份（20 级 = 3 份）。

### 1.3 拿到契约书

物品 **契约书** `LP_PactScroll`（带 Comp 记录宗主；label“契约书：阿斯莫蒂尔斯”），价值 300，不能制作。来源：
- 事件“宗主的低语”（5.1）
- 九狱商队出售（5.3）
- 塞伊法师掉落 3%
- 灵魂讨债人类的现有魔鬼事件如果设备上有，就让它的“谈判”选项多一份契约书（没有就跳过）

### 1.4 建筑 契约讲台 `LP_PactLectern`

- 2×1，木 50 / 石 50（stuff）+ 金 5，建造 1500。研究 **位面契约学** `LP_Research_PlanarPacts`：研究页 **(5, 2.8)**（开工前核对是否空，被占就往后顺延），前置 `LP_Research_Abyssology`，1800，Medieval。
- 贴图：带锁链的书架讲台，RimWorld 画风。

### 1.5 签约流程（全部用 ChoiceLetter，不做新窗口）

1. 契约书放在殖民地 → 物品右键“在契约讲台阅读”（选人）。Job：拿书到讲台，读 4 小时。
2. 读完弹信件：列出宗主、期限、三个恩赐、可见代价、隐藏条款（显示“？？？（隐藏条款）”）、偿契周期。选项：
   - **签下：恩赐 A / B / C**（三个按钮）
   - **审阅**：签约人智力豁免（`Legendary.Save(p,智力,reviewDC)`），成功揭开一条隐藏条款；然后可以再选一名殖民者当“律师”（社交或智识最高的人）再做一次（加熟练加值）。每份契约书最多审阅 2 次。审阅完重新弹信件。
   - **谈判**（只有九狱，1 次）：签约人魅力豁免 DC 16，成功删掉一条你选的可见代价（第二封信件选），失败代价 +1 条（从池里抽）。
   - **拒绝**：书销毁，签约人心情 -3“错过了机会”3 天；该宗主 60 天内不再通过低语事件出现。
3. 签下：书销毁，`Pact` 建立，恩赐生效，信件说明下一次偿契时间。设置“隐藏条款”关掉时所有条款直接可见、审阅按钮隐藏。

**种族与信仰修正**：

| 条件 | 效果 |
|---|---|
| 提夫林、坎比恩签九狱 | 审阅 +2、偿契周期 ×1.33（银子、囚犯数量不打折） |
| 精灵签妖精 | 同上 |
| 阿斯莫 | 不能签九狱（腐化 < 0.5 时“他拒绝”）；签妖精正常 |
| 巫妖签灵魂契约 | 改叫“命匣抵押”：恩赐数值 ×1.5；债务 3 时不是带走巫妖，而是命匣被收走（巫妖失去复活能力，信件；能从九狱商队赎回，见 5.3） |
| 恶神信徒（`Evil` 神） | 九狱代价周期 ×1.15 |
| 善神信徒签九狱 | 对其主神神眷 -20 |

### 1.6 偿契与违约

- 到偿契时间：信件说明这次的要求，给 **3 天**。完成 → 下一周期；没完成 → **债务 +1**，下一周期照常。
- 要求类型（`LP_PactClause.kind`，代码里一个 switch，判定在每 2500 刻的契约检查里）：

| kind | 内容 | 判定 |
|---|---|---|
| `SacrificePrisoner` | 处决一名囚犯 | 期间殖民地处决过囚犯（原版处决 / 1.54.0 炼魂都算） |
| `Silver` | 交出 N 银 | 信件按钮“交付”：从信标范围 / 仓库扣（照原版贡品的扣法） |
| `Item` | 交出一件指定类别的东西（书 / 卷轴 / 品质 ≥ 优秀的艺术品 / 灵魂币 N 枚） | 信件按钮“交付”，扣地图上的物品 |
| `Gathering` | 举办一次派对或婚礼 | 期间发生过原版派对 / 婚礼 |
| `Secret` | 一件“秘密” | 自动执行：随机两名殖民者之间关系意见 -20、各自心情 -5“秘密被公开了”5 天 |
| `Name` | 一个名字 | 自动执行：随机一名殖民者改名（随机名）、心情 -6、社交影响 -20% 10 天 |
| `Year` | 一年寿命 | 自动执行：签约人生物年龄 +1 年 |

自动执行的代价不会产生债务。

- **债务效果**：1：签约人心情 -6“违约的阴影”；恩赐的能力冷却 ×2。2：宗主派**讨债者**（九狱 → 讨债小队袭击：`LP_HellsLegion` 的链魔 / 骨魔 / 角魔，首领一名高等级角魔；妖精 → 狂猎，5.5），之后每 15 天一次直到债务降下来。3：**强制执行**——签约人被拖进位面（从地图消失，变成世界 pawn，信件）。契约结束。可以赎回：九狱 → 九狱商队“赎人”（3000 银）；妖精 → 妖精集市“赎人”。赎回后在地图边缘出现，腐化 +20%。
- **还债**：讲台 Gizmo“补偿宗主”：交付一次当期要求的双倍，债务 -1。
- **解约**：1) 圣坛“破契仪式”（挂在圣坛扩展入口）：花 **60 神眷**，50% 成功；失败签约人腐化 +30%，债务 +1。2) 讨债者首领 / 狂猎首领被击败时 100% 掉落**宗主代理人的真名卷**（1.54.0 真名卷，记录宗主）：在讲台对签约人使用 → 无代价解约。3) 格拉西娅的恩赐“解开契约”。
- 解约 / 到期 / 强制执行时：恩赐全部移除（hediff、能力、借来的守卫遣返；种族恩赐给的束缚者见各自规则）。

### 1.7 契约能力：魔能爆（所有签约人）

签约后获得能力 `LP_EldritchBlast 魔能爆`（原版 Ability，不依赖 VPE，不耗心灵熵）：射程 24，新伤害类型 `LP_Eldritch`（力场，护甲穿透 0.3），每道 12 伤害。道数随冒险者等级：1–4 级 1 道、5–10 级 2 道、11–16 级 3 道、17+ 4 道（同一目标或自动分给附近敌人）。冷却 240 刻，AI 会用。宗主附加：九狱 → 20% 点燃；妖精 → 命中后 15% 目标迷惑 2 秒（stun）。解约后移除。

## 十、本线程做的决定
