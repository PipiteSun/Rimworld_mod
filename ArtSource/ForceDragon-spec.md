# 力能龙实现要求（Peter 2026-10-23 确认）

以《力能龙构思.md》为蓝本实现，下列改动优先于构思文档：

## 删除 / 修改
1. **可以使用护盾腰带**，删掉"力场体质"基因（不再禁止腰带）。
2. **不受 EMP 影响**：力能龙被 EMP 命中不会额外眩晕，偏折力场、朦胧、错位、隐形都不会因 EMP 失效。构思里所有"怕 EMP / EMP 克星"的内容全部去掉（代谢平衡里也去掉这一项，可用其他缺点补，例如大胃口、肉食、傲慢、囤积）。
3. **去除迷宫术**。
4. **去除变身**（真龙显形、龙威形态都不做）。伟龙阶段只解锁常驻隐形和念动法球。

## 新增基因
5. **龙爪**：基因提供龙爪近战攻击（类似原版基因带来的 tools / 自然武器，锐器伤害，随龙龄提高伤害）。
6. **龙鳞**：防御基因，提供锐器 / 钝器护甲（随龙龄提高），可与"钻石鳞"外观合并或分开，二选一由实现决定，但必须有明确的护甲数值。
7. **龙体**：提高各身体部位血量（部位 HP 倍率）。模组里已有部位血量相关代码（Source/LimbHealth.cs、HealthCompatibilityChecks.cs），沿用同一机制并保证兼容性检查通过。

## 其余按构思实现
- 力能龙异种型 + 本源基因"力能龙之心"（力能资源条，类似血原质）
- 力场伤害 DamageDef，力场免疫
- 力场吐息（对建筑 3 倍伤害，打碎护盾腰带 / 机械体护盾并回复力能，不点火）
- 偏折力场（远程概率弹开，随龙龄提高，封顶 35%）
- 吞噬护盾（吃掉未装备的护盾腰带等换力能）
- 龙龄 5 阶段 hediff：天数 + 宝库价值晋升，阶段影响体型、护甲、近战、力能上限
- 宝库：卧室价值计算、宝库心情、宝库被窃心情 / 追击小偷
- 弹力法球、力墙、力场囚笼、念动法球
- 朦胧 / 错位闪避、伟龙常驻隐形
- 龙之傲慢（社交、禁止粗活、同住心情）、肉食、傲慢威压（不做恐惧）
- 龙蛋繁殖（筑巢产蛋、宝库孵化、孵出幼龙婴儿）
- 第四个剧本"龙蛋"（可选，放最后）
- 模组设置开关：龙龄门槛、宝库被窃狂暴、孵化天数
