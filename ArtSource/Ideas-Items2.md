# DND边缘大陆 物品构思（二）：1.22.0 之后还能做什么

日期：2026-10-24。只是构思，没有改代码。对照设备上模组当前文件（About.xml 已是 1.23.0，`Defs/Items_*.xml` 七个文件、`Patches/Items.xml`、`Bridges/Isekai`、`Bridges/MythicBloodlines`、`ArtSource/Items-1.22.0-report.md`）。1.23.0 巨躯规则正在另一个线程实现，这里不碰代码，只列想法。

上一轮的 [DND物品构思.md](DND物品构思.md) 第三到第十节已经基本做完。这一份先把**第一轮没做完的**列清楚，再给**新的一批**，最后给 1.24.0 的建议。设计原则不变：**规则效果优先、不堆数值、材料来自现有种族、不碰 Isekai 的精炼/符文/魔核、不做需要同调的神器**（神器留在[传奇构思](DND传奇构思.md)第五节）。

## 一、现在真正有的物品（1.22.1 / 1.23.0 核对）

| 类别 | 物品（游戏内名字） |
|---|---|
| 工作台与建筑 | 死灵仪式台、命匣、死灵重塑池、熔火锻炉、上古脑、**炼金桌**（1.22.0） |
| 研究 | 熔核锻造、**DND炼金术**、**秘金冶炼**（页签已改名“DND边缘大陆”） |
| 药水（8） | 治疗药水、强效治疗药水、巨人之力药水、抗火药水、隐形药水（只有黑网卖）、英雄药水、心智护盾药水、巨魔再生剂（附带巨魔血瘾） |
| 炼金投掷物（6） | 炼金之火、强酸瓶、圣水、黏胶袋（可制作）；雷鸣石、驱散粉尘（只能买或缴获） |

| 奇物（12） | 次元袋、精灵斗篷、精灵靴、疾行靴、心灵屏障头环、抗火/抗寒/抗酸/心灵抗性戒指、健康护符、伊奥恩石（随机技能一种）、探测魔杖；自建“饰品”栏位（`LP_Accessory`）和“盾牌”栏位 |
| 种族装备（10） | 矮人投掷锤、矮人符文盾、精灵长弓、精灵锁子甲、半兽人巨斧、牛头人角盔、星界战甲、蜕鳞甲、夺心魔触须披风、骨质护符 |

| 火巨人装备（7） | 锻工外衣、熔炉重锤、熔铁战盔、熔铁重甲、熔核破城锤、炉心战盔、熔核重甲 |
| 其他种族物品 | 力能龙蛋、银剑、夺心魔蝌蚪、脑浆罐、抑灵剂、巨魔血 |
| 配方类 | 1.22.1 的“用肉制作婴儿食品”（两档） |
| 商队 | 七个派系商队都有成品货单（`Patches/Items.xml`）；Isekai 启用时原版奇物商人卖治疗药水，地下城宝箱有额外掉落 |

一共 60 多件。消耗品、克制道具、普通人能用的 DND 装备、巨魔血的用处，这四个上一轮指出的缺口都已经补上。**现在剩下的缺口换了一批**：

1. **没有“普通”武器护甲**。除了种族装备和火巨人套装，殖民地里一个人类战士还是只能拿原版长剑。秘银、精金做成了材料，但没有一件“因为用了秘银才有意义”的样板物品。
2. **远程只有一把精灵长弓**，而且没有任何弹药层面的东西。
3. **建筑只有一张炼金桌**。命匣、宝库、上古脑这三个“种族核心系统”都没有配套家具。
4. **三条资源线（命匣经验、脑髓、力能）都没有物品化**。它们只能靠行为积累，不能储存、搬运、交易。
5. **派系没有辨识度掉落**。打败红袍法师、夺心魔、氏族火巨人之后，拿到的只是普通装备。
6. **1.23.0 之后体型有了分量**，但还没有“专门对付大块头”或“大块头专用”的物品。

## 二、第一轮遗留（先收尾）

| 项目 | 现状 | 建议 |
|---|---|---|
| 精灵靴“夜间潜入不触发警报” | 只做了“走动不吵醒人和动物”。原版没有“警报”概念 | 把“警报”定义成两件事就能做：穿着者**不会让敌方据点的守卫从睡梦中醒来**（已有），以及在敌方地图上**不会触发“殖民者被发现”的据点集结**（原版 `LordJob_DefendBase` 的敌人发现玩家后才动）。做法：穿精灵靴的人在敌人视野里距离 ≥6 格且在黑暗中时，不计入“被发现”。工作量中等，放进这一批 |
| 矮人符文盾走不走 VEF 盾牌框架 | 自写格挡（25%，山体下 45%），不依赖 VEF | **建议维持现状**。自建的“盾牌”栏位已经能复用（见第三节的龙鳞盾），接 VEF 反而多一个条件补丁 |
| 商队货单概率、Isekai 宝箱 40%～85% | 都是实现时定的默认值 | 这两项不需要新内容，Peter 玩几局后再说；如果觉得复生卷轴太常见，把教会牧师的 `-3~1` 改成 `-5~1` 即可 |
| 抗性戒指一次只能戴一枚、伊奥恩石最多 2 颗 | 已实现 | 不动 |
| 蜕鳞甲“等力能龙有美术之后再做” | 已经先做了，用的是通用贴图 | 美术问题属于[优化构思](DND边缘大陆优化构思.md)，不在这里 |
| 探测魔杖只是“放着就生效” | 已实现 | 可以顺手加一个“持有者右键扫描”模式，但优先级低 |

## 三、新一批构思

下面每一组都标了“为什么要做”和“和现有内容怎么接”。标 **[规则]** 的是原版没有的玩法，标 **[样板]** 的是让新材料/新系统有存在感的物品。

### A. 普通人能用的 DND 武器与护甲

火巨人改进思路里早就提过“火巨人为其他种族打造武器”，1.22.0 做了种族装备却跳过了这一条。这一组统一在**熔火锻炉**（火巨人制作，品质下限“良好”）和**原版锻造台**（人人能做）两处提供。

| 名称 | 槽位 / 类型 | 效果 | 说明 |
|---|---|---|---|
| **巨人杀手长枪** | 双手近战 | 对体型 ≥1.5 的目标伤害 +50%，命中大体型目标时无视 1.23.0 巨躯规则带来的额外生命（按未放大的生命算一次“穿刺”伤害）。对体型 <1 的目标 -20% | **[规则]** 直接对应 1.23.0：有了巨躯规则，就要有克制它的东西。塞伊远征军的兽人战士会带，用来打玩家的火巨人、巨魔 |
| **火巨人锻造长剑 / 战锤 / 板甲** | 普通体型装备，三件 | 数值等同原版同类，但品质下限“良好”，并且火巨人锻造的武器在火焰伤害判定上算“被火烧过”（打中巨魔会中断再生 2 小时，比炼金之火短） | **[样板]** 火巨人殖民地的出口商品；余烬氏族的“火巨人铁匠”商队卖它们。这是火巨人改进思路方向三原文 |
| **秘银胸甲** | 中层躯干 | 只能用秘银做。护甲接近板甲，但不占“外层”，可以和披风、风衣叠穿；移速无惩罚 | **[样板]** 精灵锁子甲是精灵专属加成，这件是人人都一样的“秘银为什么贵” |
| **精金战锤** | 单手近战 | 只能用精金做。对建筑和机械体伤害 ×2 已由材料给出，再加一条：击中护甲 ≥ 100% 的部位时，把该部位的服装耐久直接打掉 20 点 | **[样板]** DND 里精金武器“忽略物体的硬度”。打远征军的板甲兵、打熔核禁卫火巨人用 |
| **寒铁匕首** | 单手近战 | 寒铁材料自带对灵能单位 +25%；匕首再加：打中正在施展能力的目标时打断引导（和雷鸣石同一套中断逻辑） | **[规则]** 近战版的“打断施法”，给吉斯洋基、矮人这类冲脸的种族用 |
| **银质武器涂层** | 炼金桌配方，对一件近战武器使用 | 消耗 20 白银，给武器加 100 次命中的“银质”：对死灵造物和巫妖伤害 +50%，对神兽血裔的白泽无效（它不是亡灵） | **[规则]** 原版没有“武器涂层”，这是专长构思里“毒师”涂毒的同一套代码，先做一个银的；以后毒涂层直接复用 |
| **塔盾** | 盾牌栏位（1.22.0 自建） | 远程格挡 35%，但移速 -15%，不能和双手武器同用；格挡时相邻 1 格的友军也受保护 | **[规则]** 符文盾是矮人的，塔盾给人类和半兽人。原版没有“掩护队友”的盾 |

### B. 魔法弹药：箭袋与弩匣

原版没有弹药系统，硬做弹药会和 CE 之类的模组冲突。折中做法：**箭袋是一件腰带栏位的服装**，穿着时改变弓/弩射出的投射物。一次只能穿一件，所以“换弹药”就是换腰带，不需要任何库存管理。

| 箭袋 | 投射物变化 | 材料（炼金桌或原版工作台） | 克制 |
|---|---|---|---|
| **火箭袋** | 箭矢带火焰伤害，命中有 30% 概率点燃，触发巨魔“被火烧” | 木材 + 化学燃料 | 巨魔 |
| **银箭袋** | 对死灵造物和巫妖伤害 +50% | 木材 + 白银 | 巫妖、骷髅、红袍的造物 |
| **寒铁箭袋** | 对灵能单位 +25%，命中时打断引导 | 木材 + 寒铁 | 夺心魔、力能龙吐息、VPE 施法者 |
| **精金箭袋** | 箭矢无视 50% 护甲，但射程 -3 | 木材 + 精金（很贵） | 熔核禁卫、板甲兵 |
| **麻痹箭袋** | 命中后 5 秒移速 -50%，不叠加 | 木材 + 黏胶袋的材料 | 牛头人冲撞、近战冲锋 |

- **只对弓、弩和精灵长弓生效**，枪械不受影响，避免和工业时代武器搅在一起。
- 箭袋有耐久，每射一箭掉 1 点，射完就坏，这就是“弹药有限”。
- 精灵长弓加一条本族加成：精灵用任何箭袋时耐久消耗减半。
- 同盟的精灵草药商卖火箭袋和银箭袋；寒铁、精金箭袋要自己做。

### C. 建筑与家具：给三个核心系统配套

炼金桌是上一轮唯一的新建筑。这一组每个种族核心系统给 1～2 件家具，全部是“有它更好、没它照常玩”的东西，不加新工作台。

| 建筑 | 配套系统 | 效果 | 来源 |
|---|---|---|---|
| **命匣密室** | 巫妖 | 1×1 的厚重石龛，命匣放进去后：不会被敌人（猎巫狂热分子、远征军）优先瞄准，巫妖复生时间 -1 天；代价是巫妖离密室超过一张地图时精神力每天 -2 | [巫妖改进思路](巫妖改进思路.md)方向一的原文；这是巫妖体系里最被需要的一件东西 |
| **伪命匣** | 巫妖 | 死灵仪式台制作，50 金 + 20 玻璃钢。外观和命匣一样，猎巫者袭击时会优先去砸它；被砸毁时给巫妖一个 3 天的“被发现”debuff（远征军好感 -10） | 同上 |
| **卷轴书架** | 巫妖 / 炼金 | 2×1 储物家具，只放卷轴，容量 20 卷。放在书架附近的死灵仪式台抄写卷轴速度 ×1.5；放在室内时卷轴不会因火灾一次全烧（每卷单独判定） | 现在卷轴要么散放在地上，要么堆在架子里和药品混在一起 |
| **宝库展示柜** | 力能龙 | 1×1 玻璃柜，只放一件物品，放进去的物品按市场价 ×1.3 计入宝库价值，且不会被“宝库被窃”逻辑搬走（偷宝者要先砸柜子）。龙看到满柜子的展示柜心情 +1（最多 +3） | 让“建宝库”从堆钱变成布置房间；神兽血裔联动里“狻猊点化过的宝物 +10%”可以叠加 |
| **龙之王座** | 力能龙 | 2×2 大椅子，只有龙能坐。坐着时力能回复 +50%，并且在它所在房间里偏折力场的冷却 ×0.8 | 伟龙有了“巢穴里的位置”，也为传奇构思的“巢穴动作”预留一个锚点 |
| **脑髓培养槽** | 夺心魔 | 1×1 建筑，接上古脑旁边使用。把一个脑浆罐放进去，7 天后产出 3 份**脑髓浓缩剂**（见 D 组）。没有上古脑时不能工作 | 给没有敌人可吞的和平期夺心魔一条活路，但产量故意很低 |
| **熔岩池** | 火巨人 | 2×2 装饰兼功能建筑，需要靠近熔火锻炉。火巨人站在里面“泡澡”：心情 +4，舒适度满，并且 15% 的熔岩结晶产出概率提高到 25%。非火巨人进去会被点燃 | 火巨人到现在没有一件专属家具，矮人看到火巨人 -3 的关系心情也可以改成“看到熔岩池 -1” |
| **巨魔血库** | 巨魔 | 1×1 冷藏柜，只放巨魔血，放进去的巨魔血不会腐坏（现在它是普通物品，没有腐坏；加腐坏是另一条建议，见第五节问题 2） | 可选，只有决定让巨魔血腐坏时才有意义 |
| **守卫石像** | 卷轴 | 不是新建筑，是给 1.22.0 的“石像”物品加一个用途：把石像放在殖民地里，敌人路过会被它“看到”（触发一次警报），相当于不用电的动作传感器。石像里的人仍然可以用驱散粉尘复原 | 石化卷轴现在用完就是一块废石头，这让它有了第二用途 |

### D. 把三条资源线物品化：命匣经验、脑髓、力能

这是我最想推的一组，因为它让种族核心机制**能储存、能搬运、能交易、能跨种族用**，而且每件都是消耗品，工作量小。

| 物品 | 资源线 | 做法 | 用途 |
|---|---|---|---|
| **灵魂宝石** | 命匣 | 死灵仪式台配方：巫妖消耗 100 献祭经验 + 1 翡翠，做成一颗宝石。任何巫妖在仪式台“碎掉”它可以拿回 80 经验 | 第一次让命匣经验可以**转移**（两个巫妖之间、新旧存档的巫妖之间）和**交易**（红袍商人高价收，也偶尔卖）。和事件构思里“红袍招揽巫妖、上缴灵魂”接得上：以后上缴可以直接交宝石 |
| **封魂容器** | 命匣 / 造物 | 对一具完整人形尸体使用（不限巫妖），把“汲取灵魂”本来会给的经验封进容器，容器保存 30 天。巫妖之后在仪式台打开 | 解决“尸体腐烂前巫妖赶不回来”的问题；远征队带着容器出门就能带灵魂回来 |
| **脑髓浓缩剂** | 脑髓 | 由脑髓培养槽产出，或黑网商队罕见出售。夺心魔喝下脑髓 +25。**非夺心魔喝下**：24 小时智识学习 ×1.5，之后 3 天头痛（意识 -10%） | 第一件让“脑髓”走出夺心魔的东西；玩家没有夺心魔也会想买黑网的这个 |
| **力能结晶** | 力能 | 力能龙在宝库里“凝结”：花 50 力能 + 1 龙鳞蜕做一颗。任何人（含非龙）右键使用：获得一次**力墙**或**弹力法球**（做成一个可选菜单，两种结晶）。龙自己用是回 40 力能 | 让力能龙的法术第一次能借给队友；也是“屠龙战利品”的高端版本 |
| **龙息瓶** | 力能 / 投掷物 | 力能龙对一个空瓶子“吐息”（花 30 力能）得到一瓶，投掷后在落点放一次弱化的力场吐息（半径 2，伤害减半，照常拆墙） | 和炼金投掷物并列，但只有养龙的殖民地有 |
| **火巨人心火** | （火巨人没有资源条，用冷却代替） | 熔火锻炉配方，火巨人 7 天只能做一份：消耗 5 熔岩结晶。非火巨人喝下 24 小时火焰免疫 + 近战 +10%；火巨人喝下“炉心过载”冷却立刻完成 | 让火巨人也有一样“输出给队友”的消耗品，和其他三个种族对称 |

### E. 龙蜕与屠龙战利品（龙鳞蜕的第二批用途）

龙鳞蜕现在只做蜕鳞甲。再加三件小的，全部在原版锻造台做，不需要新系统：

| 名称 | 栏位 | 效果 |
|---|---|---|
| **龙鳞盾** | 盾牌栏位 | 远程格挡 30%；**完全免疫力场类伤害**（力场吐息、弹力法球撞击），EMP 不会击晕穿戴者 |
| **龙牙匕首** | 单手近战 | 用龙鳞蜕 + 钢。命中时有 10% 概率触发一次“小型力场爆发”（1 格击退，和 `DNDPush` 共用） |
| **龙鳞护符** | 饰品栏位 | 戴着它的非龙，力能龙对他的“龙之傲慢”心情不触发；龙看到它心情 -1（“我的鳞片在别人脖子上”），除非是它自己送出去的（做一个“赠予”右键） |

**龙的反应**：卖掉龙鳞蜕已经会让龙“被冒犯”，这三件做出来后龙不会再记仇（鳞片留在家里了）。这是让玩家“把龙蜕用掉而不是卖掉”的推力。

### F. 派系特色掉落：打败谁，就拿到谁的东西

每个派系给 1～2 件**只有它掉**的物品，掉落概率放在领队/精英身上，普通成员不掉。和 1.19.0 斩首机制接上：领队倒下才有。

|---|---|---|

## 五、1.24.0 建议：做哪些、按什么顺序

按“玩家最快感受到 + 工作量最小 + 和 1.23.0 衔接”排，分三档。

### 第一档（建议 1.24.0 一定做，约 25 件）

1. **D 组全部六件**（灵魂宝石、封魂容器、脑髓浓缩剂、力能结晶、龙息瓶、火巨人心火）。全是消耗品 + 一条配方，C# 都是现成接口（命匣经验、脑髓、力能、炉心过载冷却），但它们让四个种族第一次“能把自己的东西给别人”。
2. **C 组里的命匣密室、伪命匣、卷轴书架、宝库展示柜、脑髓培养槽**。五件建筑，每个核心系统一件，脑髓培养槽是 D 组脑髓浓缩剂的产地。
3. **A 组的巨人杀手长枪 + 火巨人锻造三件**。巨人杀手直接对接 1.23.0 巨躯规则，火巨人锻造三件是火巨人改进思路里欠了两个版本的东西。
4. **F 组全部七件派系掉落**。模板最简单（饰品/一次性），叙事价值最高。
5. **精灵靴的“潜入不被发现”**（第二节遗留），顺手收掉第一轮最后一个未完成项。

### 第二档（1.24.0 有余力就做，否则 1.24.1）

6. **B 组五种箭袋**。需要一个“腰带改投射物”的补丁，写一次五件都有了。
7. **E 组三件龙蜕物品**，和宝库展示柜一起让养龙更有事做。
8. **A 组剩余**：秘银胸甲、精金战锤、寒铁匕首、银质涂层、塔盾。

### 第三档（看反馈）

9. G 组卷轴四种、C 组的龙之王座、熔岩池、守卫石像、H 组联动。

### 工作量和测试

- 第一档几乎全是原版模板（可摄入物、饰品、储物家具、配方）加短 C#；最花时间的是命匣密室的“被优先瞄准”逻辑和精灵靴的“被发现”判定，各算半天。
- 贴图照 `ArtSource/RaceArt/draw_item_art.py` 的流程补，第一档约 25 张。
- 检查写进 `ItemChecks.cs`（已经 98 KB，建议拆一个 `ItemChecks2.cs`），测试矩阵沿用 Core / -Mythic / -Isekai / -Full。
- 不改 1.23.0 的 `BodySize.cs`，巨人杀手只读体型，不写。

## 六、需要你决定的问题

1. **巨人杀手长枪会不会削弱玩家自己的火巨人、巨魔？** 敌人（远征军兽人）会带它。可以把“敌人携带”做成设置项，默认开。
2. **巨魔血要不要加腐坏？** 现在它永不腐坏，药水材料太好囤。如果加（比如 15 天），就要同时做巨魔血库。我的建议是加，但只在 1.24.0 的新存档生效。
3. **灵魂宝石允许交易吗？** 能卖给红袍商人意味着巫妖多了一个赚钱手段；能买意味着命匣可以用钱升级。建议：**只卖不买**，红袍商人高价收购（每颗约 400 银），不出售。
4. **脑髓浓缩剂给非夺心魔用的副作用**（3 天头痛）够不够？不够的话可以换成“10% 概率染上一只蝌蚪”，更 DND，也更吓人。
5. **派系掉落的唯一性**：氏族传承锤整局只掉 1 把，其他六件每次领队倒下都有 30% 概率。要不要全部做成“整局唯一”？
6. **箭袋只对弓弩生效**，还是也对精灵长弓之外的模组弓（比如 VFE 中世纪的弩）生效？按“有 `Bow`/`Crossbow` 标签的远程武器”判断可以自动覆盖大部分模组。
7. **命匣密室的代价**（巫妖离开地图时精神力 -2/天）会不会让巫妖不敢出远门？备选：改成“离开超过 10 天才开始扣”。

### 5. 从这张清单里挑一个“经典装备包”

如果 1.24.0 想单独做一个“DND 经典装备”主题（和第五节的建议并行或替代），我挑 **12 件**，全是 ★ 或和现有种族接得最紧的：

| 件 | 接哪条线 | 实现难度 |
|---|---|---|
| 火焰舌、霜寒之刃 | 巨魔克制 / 火巨人锻造 | 低（命中附带伤害） |
| 锐锋剑 | 复用斩首代码 | 低 |
| 龙杀手 | 力能龙 / 屠龙者事件 | 低 |
| 箭引盾、接箭手套 | 自建盾牌栏位 / 投射物拦截 | 中（投射物重定向要一个补丁） |
| 食人魔之力手套 | 1.23.0 体型规则的反向（给小个子） | 低 |
| 传心头盔 | 夺心魔读心 | 低（能力已有） |
| 伤口闭合护符 | 治疗药水 / 巨魔再生的对照 | 低 |
| 不可移动之杖 | 临时墙 | 中（放置 / 收回） |
| 无尽水瓶 | 灭火、巨魔 | 中（地形 / 灭火） |
| 魔像手册 → 石魔像 | 死灵造物第四种 | 中偏高（新造物模板，但骷髅/巨像的代码都能抄） |

来源分配：火焰舌、霜寒之刃、龙杀手在熔火锻炉由火巨人做；锐锋剑、箭引盾只能缴获（远征军吉斯洋基雇佣兵、同盟圣武士）；手套、护符、头盔走同盟商队和黑网；不可移动之杖、无尽水瓶、魔像手册只在 Isekai 地下城三级以上宝箱和黑网出现。

这 12 件加起来的工作量大约等于第五节第一档的一半。如果两边都想要，建议 **1.24.0 做第五节第一档，1.25.0 做经典装备包**；如果只选一个，经典装备包更“像 DND”，第五节第一档更“像这个模组”。
