# DND边缘大陆：帅气盔甲与衣服构思

> 2026-10-25，按模组 1.25.0（RimWorld 1.7）写。**只是构思，没有实现。**
> 写之前对照过：《DND边缘大陆内容总览》《DND物品构思》《DND物品构思二》《魔法饰品构思》《种族1.24.0实现要求》《DND派系构思》。

## 一、为什么做、做成什么样

《物品构思二》点过一个缺口：**普通人没有像样的 DND 护甲**。现在一个人类圣武士只能穿原版板甲，红袍法师穿的是原版衣服，袭击打过来看不出是“费伦”。这一批的目标就是三件事：

1. **一眼认得出职业**：骑士、游侠、法师、牧师、游荡者、死亡骑士，看剪影就知道是谁。
2. **给派系换装**：同盟圣武士穿圣武士板甲，红袍法师穿塞伊红袍，殖巢奴仆、余烬奴兵各有制服。这一步投入最小、观感提升最大（见第九节）。
3. **数值不膨胀**：大部分装备的数值贴着原版同档（以“原版板甲的 X%”来描述，不写死数字），特色放在一两条小效果和套装效果上。Isekai 的强化、符文都能照常用在这些衣服上，所以不另做强化系统。

### 已有的服装，这次不重做

| 类别 | 已有 |
|---|---|
| 火巨人专属 | 锻工外衣、熔铁战盔、熔铁重甲、炉心战盔、熔核重甲（熔核禁卫套装） |
| 种族装备 | 精灵锁子甲、牛头人角盔、吉斯洋基星界战甲、蜕鳞甲、夺心魔触须披风、风羽披风、矮人符文盾 |
| 奇物 | 精灵斗篷、精灵靴、疾行靴、心灵屏障头环 |
| 构思过未做 | 秘银胸甲、塔盾、龙鳞盾、箭引盾、位移斗篷、防御护腕、传心头盔（物品构思二）；各种戒指、护符、圣光冠环、灵能兜帽（魔法饰品构思） |

这些里有几件**外观值得返工**（星界战甲、精灵锁子甲现在用的是通用剪影），放在第十节当可选项。

## 二、通用美术规则（所有新衣服都照这个做）

### 1. 双色遮罩，让“材料色”和“纹章色”分开

“帅气”的关键是**两种颜色**：主体随材料变（钢是银灰、金是金色、秘银是淡蓝白），饰边和罩袍用固定色或意识形态色。原版支持这个：贴图用 `CutoutComplex` 着色器加一张 `_m` 遮罩图，红通道吃材料色，绿通道吃第二色。

- **纹章色**默认取穿戴者意识形态的颜色（原版的 `useIdeoColor` 思路），没有意识形态就用派系色。这样玩家的骑士团自动穿自家颜色，袭击方的圣武士穿同盟的白金色。
- 每件衣服下面都写了“主色 / 副色”，主色 = 材料色区域，副色 = 固定色或纹章色区域。

### 2. 贴图规格

- 照 1.22.0 精灵锁子甲、触须披风、1.24.0 风羽披风的做法：**五体型（男、女、瘦、胖、壮硕）× 三向（南、东、北）** 的 Worn 贴图，加一张 256px 图标。
- 继续用 `ArtSource/RaceArt` 下的 Python 画图脚本出图，新脚本建议叫 `draw_apparel_126.py`，复用现有调色和形状函数。程序画图最容易“扁平”，所以每件都要求三层明暗（暗面、本色、高光描边）和一条清楚的外轮廓线。出一张预览总图 `ArtSource/Preview/Apparel-1.26.0.png`，四向并排，方便 Peter 一次看完。
- **女性体型不是“换胸甲曲线”那么简单**：板甲类女版收腰、裙甲更长；袍子类女版下摆展开更宽。男版肩更宽、肩甲更大。
- **胖体型**的板甲肩甲加大、腰部用分段甲片，不要直接拉伸。

### 3. 头盔和种族头部

| 种族 | 问题 | 处理 |
|---|---|---|
| 精灵、半精灵 | 长耳朵被全盔盖住 | 精灵款头盔（翼盔、林行者兜帽）留耳孔；全盔照常盖住 |
| 牛头人 | 牛角 | 全盔用 `renderSkipFlags` 不隐藏角附件，贴图在角的位置留开口；或者全盔直接隐藏角（问题 4） |
| 象人 | 象鼻 | 全盔下沿开口；象人卫士重铠自带鼻甲 |
| 鸟人 | 翅膀 | Shell 层的斗篷、披风对鸟人画成“开背”款（翅膀从两侧伸出），代码上让翅膀附件画在斗篷之上 |
| 火元素裔 | 火焰头发 | 兜帽、尖顶帽照常盖，全盔照常隐藏头发 |
| 矮人 | 胡子 | 胡须面甲盔隐藏真胡子，换成金属胡子 |

### 4. 大体型怎么处理

- 1.24.0 起大体型都用 `SmallBodyExtension` 放大 `renderScale`，衣服会跟着身体一起放大，**不用单独画大号贴图**。壮硕体型（Hulk）的贴图要画得足够细，放大 1.3 倍（食人魔、象人）还看得清，放大 1.6 倍（泰坦）以后线条不糊。
- **火巨人不能穿普通衣服**，这是早就定下的设定，这次不改。火巨人风格的装备还是走熔火锻炉的专属线（见第八节）。
- **泰坦、食人魔、象人、巨魔**可以穿普通衣服，这次的所有衣服都能穿。另外给泰坦和象人各做一件专属的（第七节）。
- 寒冰魔、炎魔只出现在塞伊远征军里，不穿衣服，不处理。

### 5. 披风放哪一层

骑士披风、红袍披肩这种“最外面飘着”的东西是帅气的大头，但原版 Shell 层已经被板甲占了（原版板甲占 Middle + Shell）。两个办法：

- **默认**：装了 VEF 时用 `VFEC_OuterShell`（顶层，Peter 的存档里已经有这一层）；没装 VEF 时这几件披风退回 Shell 层。
- 或者自建一个 `LP_Cape 披风` 层（问题 2）。

## 三、骑士与圣武士（费伦拓荒同盟）

同盟的骑士团风格：**亮钢 + 白罩袍 + 金饰边 + 晨主（拉森德）的旭日纹章**。

### 1. 圣武士板甲 Paladin's Plate

- **部位**：躯干、颈、肩、手臂、腿；Middle + Shell（和原版板甲一样）。
- **外观**：
  - 剪影：圆润的大肩甲（左右对称，边缘外卷），胸甲中脊起棱，腰下垂一片到膝的白色罩袍前摆。
  - 主色：材料色（钢 = 冷银）。副色：纹章色，画在罩袍、肩甲内衬和胸口的旭日纹上。
  - 贴图要点：胸口一个 8 芒旭日浮雕（金色描边，不随材料变）；北向能看到背后的罩袍后摆和腰带扣。
  - 女版：收腰，罩袍前摆分叉；男版：肩更宽。
- **属性**：护甲为原版板甲的 100%，移速惩罚同原版。小效果 **“圣盾之誓”**：受到死灵伤害（巫妖法术、死亡骑士、骷髅）-20%。
- **获取**：研究“骑士锻造”（中世纪，前置：板甲）后在锻造台制作，钢 150 + 金 10；同盟商队偶尔卖。

### 2. 誓约巨盔 Great Helm of the Oath

- **部位**：全头（Overhead，FullHead），隐藏头发。
- **外观**：桶形巨盔，十字形观察缝；盔顶一根羽饰（副色 = 纹章色），侧面一圈金边。北向能看到羽饰垂到后颈。羽饰是这件的灵魂，画大一点。
- **属性**：头部护甲比原版简易头盔高一档（约原版先进头盔的 80%），视野惩罚：瞄准时间 +5%（全盔看不清）。
- **获取**：同圣武士板甲。

### 3. 骑士披风 Knight's Mantle

- **部位**：顶层（见 §2.5），覆盖躯干和肩。
- **外观**：从双肩垂到脚踝的长披风，肩部用两枚圆形扣针固定；外面纹章色，里衬深红或深蓝；下摆微微飘开（东向画出 15° 的后摆）。北向是一整面纹章色，中间绣旭日。
- **属性**：几乎没有护甲（锐器 +4%），保暖 +4℃，美观 +2。小效果 **“旗帜”**：穿戴者 5 格内的友军精神崩溃阈值 -2%（同类效果不叠加）。
- **获取**：裁缝台，布料 60 + 金 5，不需要研究。

**套装 “白银骑士团”**（圣武士板甲 + 誓约巨盔 + 骑士披风）：穿齐时获得能力 **“坚守誓约”**：15 秒内受到的伤害 -40%，期间不能移动；冷却 1 天。参照火巨人“炉心过载”的套装写法。

### 4. 锁子甲衫 Chain Shirt（普通人的基础护甲）

- **部位**：躯干、肩；Middle。可以外面再套斗篷、袍子、风衣。
- **外观**：灰色链环纹路的及臀甲衣，领口和袖口有皮革包边。用一张链环纹理重复平铺，配一条暗色腰带。
- **属性**：锐器护甲约原版防弹背心的 70%，钝器低；没有移速惩罚，工作速度 -3%。这是**最便宜的“中世纪中甲”**，填原版从“没甲”直接跳到“板甲”的空档。
- **获取**：锻造台，金属类材料 60，研究“锻造”即可。所有同盟、远征军的普通兵都可以穿。

## 四、矮人（同盟矮人铁匠）

矮人风格：**矮宽厚重 + 青铜金饰边 + 发光符文**。

### 5. 矮人符文重铠 Dwarven Runeplate

- **部位**：同板甲。
- **外观**：
  - 剪影：方肩、粗腰、腿甲到靴面；肩甲是两块厚板，像城墙垛口。
  - 主色：材料色（推荐配精金：暗紫黑）。副色：固定青铜金，画在每块甲片的边缘。
  - 胸口一排三个菱形符文，画成浅冰蓝色（RimWorld 没有自发光，就用高亮像素加一圈暗边“假发光”）。
  - 壮硕和胖体型是主力体型，画得最用心。
- **属性**：钝器护甲比原版板甲高 15%，锐器同原版；移速惩罚同原版，**矮人穿时惩罚减半**。头顶有山体（洞里、山里的房间）时锐钝护甲各 +10%。
- **获取**：只有矮人能在锻造台做（不要求研究，矮人天生会），钢 180 + 金 15；矮人铁匠商队稀有货。

### 6. 胡须面甲盔 Bearded Faceplate Helm

- **部位**：全头，隐藏真胡子。
- **外观**：圆顶盔加一块铸成辫子大胡子形状的金属面甲，胡子是副色青铜金，两根辫梢各挂一枚小铁环。很搞笑也很帅，是矮人的招牌。
- **属性**：头部护甲约原版先进头盔的 90%；美观 +1；社交影响 -5%（看不到嘴）。
- **获取**：同上。

## 五、游侠与游荡者

### 7. 游侠皮甲 Ranger's Leathers

- **部位**：躯干、肩、手臂；Middle。
- **外观**：深棕硬皮胸甲，胸前交叉两条带子（挂箭袋的样子），左肩一片单肩甲。副色固定苔绿，画在肩甲和腰间的布带上。
- **属性**：锐器护甲约原版防弹背心的 60%，无移速惩罚；**狩猎隐匿 +20%**（原版 `HuntingStealth`）；远程瞄准时间 -5%。
- **获取**：裁缝台，皮革 70，研究“复合弓”（游侠的感觉）。

### 8. 林行者兜帽斗篷 Woodwalker's Hooded Cloak

- **部位**：Shell + 头顶（一件同时占斗篷和兜帽）。
- **外观**：
  - 苔绿到墨绿渐变的长斗篷，下摆剪成锯齿树叶状，边缘一圈浅一点的叶脉纹。
  - 兜帽是戴起的，帽檐压到眉上，**南向能看到眼睛和下半张脸在阴影里**（脸上半部压一层半透明暗色）。精灵款留耳孔。
  - 鸟人开背款。
- **属性**：保暖同原版斗篷；狩猎隐匿 +15%；在树木、灌木格子里被远程命中 -10%。（和魔法的精灵斗篷分开：精灵斗篷是“站着不动”，这件是“在林子里”。）
- **获取**：裁缝台，布料或皮革 80；同盟精灵草药商常备。

**套装 “游侠”**（游侠皮甲 + 林行者斗篷）：驯服和狩猎速度 +15%，殖民地外的野生动物不会主动攻击穿戴者。

### 9. 暗影斗篷 Shadowweave Cloak

- **部位**：Shell。
- **外观**：
  - 炭黑色及膝斗篷，高立领遮到鼻子下面，里衬暗红（东向走动时露出一角红，很关键）。
  - 一侧肩上搭一段斜垂的披肩，腰间斜挂两把匕首的皮鞘（画在斗篷上，不是真武器）。
  - 女版收腰，下摆分叉。
- **属性**：几乎无护甲；**光照低于 30% 的格子里被远程命中 -20%、移速 +5%**。
- **获取**：裁缝台，布料 70 + 黑色染料（如果装了 Ideology 染料就用染料，否则不要求）；黑网商队常备。

### 10. 游荡者面罩 Rogue's Half-Mask

- **部位**：眼部（EyeCover 层，原版眼罩那一层），只盖下半张脸。
- **外观**：黑色布面罩从鼻梁盖到下巴，眼睛露出来；和暗影斗篷的立领连成一片。
- **属性**：近战命中 +3%；社交影响 -10%；**在别人殖民地或派系据点里，被识别出来的概率降低**（如果以后做潜入/偷窃，这里就是挂钩；现在只给数值）。
- **获取**：裁缝台，布料 15。

**套装 “影行者”**（暗影斗篷 + 游荡者面罩 + 精灵靴）：第一次近战攻击一个还没进入战斗状态的敌人时，伤害 ×1.5（“偷袭”）。每个目标只算一次。

## 六、法师、牧师与红袍

### 11. 大法师长袍 Archmage's Robe

- **部位**：躯干、肩、手臂、腿；Shell。
- **外观**：
  - 深靛蓝及地长袍，高领向外翻，两只袖子是宽口喇叭袖（东向画出下垂的袖摆）。
  - 副色固定银白：领口、袖口、下摆各一圈星辰与新月刺绣，胸前一条银色饰带。
  - 主色随布料（超织物 = 灰紫，恶魔菌丝 = 深红，所以玩家能自己调颜色）。
  - 女版下摆更宽，腰间一条细银链。
- **属性**：护甲很低（约原版风衣的 50%）；**心灵敏感度 +10%**；读卷轴失误率 -50%（1.22.0 卷轴有失误判定，这里减半，红袍施法焦点是直接免失误，两者叠到 0）；巫妖穿时死灵冲击冷却 -10%。
- **获取**：裁缝台，布料 100 + 金 10，研究“复杂服装”。

### 12. 尖顶法师帽 Wizard's Pointed Hat

- **部位**：头顶（Overhead，不隐藏头发）。
- **外观**：宽檐尖顶帽，帽尖向后弯折一下（东向最明显），帽带上一颗银星。颜色随布料，和长袍同色就成套。帽子高度要画够，大概占头高的 1.3 倍，这是剪影辨识度的来源。
- **属性**：心灵敏感度 +5%；美观 +1；没有护甲。
- **获取**：裁缝台，布料 30。

**套装 “大法师”**（长袍 + 尖顶帽）：每天第一次读卷轴不消耗卷轴（50% 概率）。

### 13. 塞伊红袍 Red Wizard's Robe

- **部位**：同大法师长袍，另带一件**红袍披肩**占顶层。
- **外观**：
  - 正红色长袍，黑色宽腰封；下摆和袖口是**黑底金线的几何纹**（塞伊的锐角符文，三角和折线），和同盟的圆润花纹形成对比。
  - 披肩是黑色，肩部有两片尖角的硬肩（像小翅膀），这是红袍最强的剪影。
  - 塞伊红袍法师都是光头带纹身：这件衣服配一个可选的“头部纹身”外观（如果原版纹身系统可用就用，Ideology 有面部纹身）。
- **属性**：同大法师长袍；另外 **“塞伊的威势”**：穿戴者指挥的死灵造物（骷髅、巨像）移速 +10%。**同盟商队来访时，穿着红袍的殖民者会让同盟好感 -5（每次来访，只算一次）**。
- **获取**：**不能制作**。塞伊远征军的红袍法师必穿、缴获（倒地剥下来照常是“死人衣服”，所以要俘虏或者打晕扒）；巫妖效忠红袍后，红袍卷轴商会卖。

### 14. 晨主圣袍 Vestments of the Morninglord

- **部位**：躯干、肩、手臂、腿；Shell。
- **外观**：
  - 象牙白长袍，外罩一条从双肩垂到膝下的金色圣带（stole），圣带末端绣旭日。
  - 胸口一枚大的旭日圣徽（金色，固定色）；腰间一条朱红布带。
  - 北向：背后是一大片放射状的金色日芒刺绣，这是这件最好看的角度。
- **属性**：护甲很低；**医疗手术成功率 +5%、医疗速度 +10%**；受到死灵伤害 -10%。
- **获取**：裁缝台，布料 90 + 金 15；同盟牧师必穿（派系换装）。

### 15. 战斗牧师胸甲 Battle Cleric's Breastplate
