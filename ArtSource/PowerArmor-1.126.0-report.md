## 决定
1. 版本号：本来是 1.124.0，因 UI 整理（1.124.0）和近战武器（1.125.0）先占用，按协调改为 1.126.0。
2. 3 档 + 3 职业变体（圣誓 / 秘法炮手 / 奇械），变体共用骑士档数值和骑士盔，只差加成和能力组合；头盔 3 顶。
3. 新建「奥械锻炉」（要电）而不是用符文铁砧：动力甲是太空档科技，烧木头的铁砧不合适；锻炉也做电池。
4. 研究放在自己的 PowerArmor.xml，坐标接在传奇战甲 (3,3.5) 右边，避免改共享的 Research.xml。奥能动力学另需原版「微电子学基础」（研究前置可以是原版，物品只认本页研究）。
5. 能量只在受击、征召和能力时消耗，不自然回复；充能只靠充能座和电池。殖民者不会自己去充能（避免打断工作），用盔甲上的「充能」按钮或右键充能座。
6. NPC 不会主动放装甲能力（只穿着），但同样会受击掉能量、变铁壳。
7. 奥术 / 神恩强度加成不用 equippedStatOffsets：强度属性由 StatPart_ClassPower 整个重算，装备偏移会被盖掉；改为追加 StatPart_PowerArmor（测试发现的问题）。
8. 与装甲师联动：装甲师把动力甲改成奥术装甲时核心上限 +50%（装甲师原有改装效果照旧）。
9. 不卖：交易标签只有 LP_PowerArmor，原版商人不会带。
10. 力场没有画气泡（避免碰 1.7 多线程渲染），用状态栏「奥能力场」+ 闪光表现；本次没有任何渲染缓存。
11. 堡垒的大轮廓直接画在贴图里（加宽 24%、塔盾肩甲），没用 renderScale；宽体型（壮硕 / 肥胖）的肩甲按画布宽度缩小，不出画布。
