# 1.99.0 属性页说明修正（数值不变）

Peter 截图问体质的倍数怎么来的。核对代码后，所有数值都和代码一致，没有重复乘；问题在显示文字：有一处过时（等级成长），有一处口径不一致（冒险者页的部位生命）。

## 截图数值逐项核对（体质 19 (+4)、种族擅长 ×1.5、极致 ×2.5、冒险者 2 级、坚韧 ×1.04）
- 调整值 = floor((19 − 10)/2) = +4；调整值′ = 4 × 种族 1.5 = 6（Adventurer.cs:429 AMod，种族只放大正的调整值）。
- M = Curve(19) × ScoreMult。Curve 是同一张 3.5 负重表：10～19 依次 1 / 1.15 / 1.3 / 1.5 / 1.75 / 2 / 2.3 / 2.6 / 3 / 3.5（Adventurer.cs:31-32），力量 14 → 1.75，体质 19 → 3.5。没有给“擅长”另设的表，也不按调整值′查表。ScoreMult = 有天赋时 max(种族, 天赋) = max(1.5, 2.5) = 2.5（AdventurerAffinity.cs:121），M = 3.5 × 2.5 = ×8.75。
- 用 M 的效果（只取较大的一个，种族 1.5 被 2.5 盖掉）：伤口愈合 ×8.75（上限 10 内）；免疫 5 + 2.5·ln(1 + 3.75/2.5) = ×7.29；休息 3 + 1.5·ln(1 + 5.75/1.5) = ×5.36；疼痛休克 / 毒素 5% × 7.75 = +38.8%；护甲 3% × 7.75 = +23.3%。
- 线性效果（调整值′ 已含种族，整体再 × 天赋，种族和天赋相乘）：部位生命（体质）(1 + 15% × 6) × 2.5 = ×4.75（Adventurer.cs:697）；职业强度 (1 + 5% × 6) × 2.5 − 1 = +225%（Adventurer.cs:258）。
- 等级成长 ×1.08：1.93.0 公式 1 + Σ 职业等级 × 生命骰成长 + 未分配 × 4% − 4%；冒险者 2 级、两级都在战士类（6%）时 = 1 + 12% − 4% = ×1.08（Adventurer.cs:688-692）。
- 部位生命合计 = 4.75 × 1.08 × 坚韧 1.04 = ×5.34（Adventurer.cs:251）；伤口疼痛 ÷5.34。
- 冒险者页 +413% = 4.75 × 1.08 − 1，用的是 PartFactor，不含坚韧 / 传奇血量 —— 和属性页 ×5.34 口径不同。

结论：M 取较大、线性效果相乘，是两套不同效果各自的规则（1.81.0 热修5 起的设计），同一个效果里没有重复乘。实际数值没有 bug。

# 1.99.0 不睡觉的种族恢复职业资源（同一版本）

Peter：巫妖、构装体等没有睡眠 / 进食需求的人回不了职业资源。

## 原来怎么恢复（Classes.cs Regen，每 250 刻）
| 资源 | 睡觉 | 醒着 | 其他 |
|---|---|---|---|
| 斗志（战士） | +0.5 | — | 命中 / 击杀敌人 |

| 怒气（野蛮人） | 不回 | 战斗获得、脱战衰减 | |

吃饭在代码里不回任何资源，所以“没有进食需求”本身不影响；问题只在“没有休息需求”的人永远不会睡着（每晚靠睡觉回满的那部分没了）。

## 新的恢复（Source/ClassRestless.cs、Defs/ClassRestless.xml）
- 条件：`needs.rest == null`（或没有 needs）；醒着、已生成、未征召、没倒地、不在战斗中（`ClassSubclass.NotInCombat`：没有敌对目标、600 刻内没受伤也没攻击）。
- 每 250 刻回每条资源上限的 1/240 → 每 6 小时 1/4，一整天回满。适用斗志、气、神恩（共用池只回一次）、法力、契约法力、诡术师法力；怒气不变。
- 按钮“冥想调息”：只给玩家阵营、没有休息需求、有上面这些资源的人；征召 / 倒地 / 战斗中灰掉。原地静坐 5000 刻（2 小时），结束时全部回满；被打断没有效果。用 JobDef `LP_Attune` + `JobDriver_Attune`，按钮是 Command_Action，没用浮动菜单。
- 会睡觉的人：`NoSleep` 为假，新代码完全不执行，不会双倍恢复。
- 资源条悬停（ClassSystem.ResourceTip）补一句不睡觉种族的恢复方式。
