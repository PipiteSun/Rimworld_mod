## 实现
- **实现方式**：原版 Site（通用站点 `LP_AB_Site`，没有派系）+ `GenStep_AdventureSite`：地图生成时按站点找到委托，交给委托类型的 Worker 放敌人和目标。接受后生成原版任务（任务分页能看到、能定位目标），任务点数设 0，经验由委托板按参与者给。
- **委托类型 = Def + Worker**：`LichPhylactery.AdventureKindDef`（label、description、workerClass、weight、legendary）+ `AdventureWorker`（CanOffer / Setup / Enemies / Generate / Done / SurvivesSite / Status / OnComplete）。以后加类型只要写一个 Def 和一个 Worker。
- 刷新：每 N 天（默认 5）3 条，到时没接的消失；告示板在殖民地上才刷新。同时最多接 2 条；接下 7 天内完成，否则失败、名声 -3、地点撤掉。地点离殖民地 2～8 格（按行走距离筛）。
- 推荐等级 = 殖民地冒险者等级最高 3 人的平均 ±2：危险度低 -2、中 0 或 ±1、高 +1、致命 +2；三条里至少一条低或中；名声越高，高 / 致命的权重越大。威胁点数 = (200 + 90 × 推荐等级) × 难度倍率（致命再 ×1.2），不看财富。
- 五种类型 + 传奇：
  1. 清剿怪物巢穴：DND 魔兽（探索公告板魔物来袭用的那 12 种：闪光犬、锈蚀怪、邪座狼、冬狼、地狱犬、魔化兽、腐肉爬行者、凝胶怪、蛇怪、枭熊、蝎尾狮、掘地兽），优先当地生物群系会出现的；永久狂暴；全清完成。
  2. 讨伐通缉犯：塞伊远征军（没有就随机敌对派系）的首领 + 护卫，首领冒险者等级 = 推荐等级 + 2，用 NPC 职业系统分配职业；击杀完成，关进囚室完成并 ×1.25。
  3. 救援被困冒险者：友方派系（费伦拓荒同盟，没有就随机友好派系）的冒险者倒地，周围是魔兽；活着带到殖民地地图上完成，然后弹窗选「招募」或「领赏（当前报酬的一半）」。
  4. 寻回失物：遗物 + 看守（敌对派系的守卫队，没有就魔兽）；遗物到了殖民地地图上（地上或殖民者身上）完成，遗物交还委托人（消失）。
  5. 调查闹鬼废墟：亡灵（骷髅仆役、血肉巨像）+ 亡灵之源；摧毁亡灵之源完成。
  6. 讨伐传奇魔物（名声 ≥ 90 时每次刷新 25% 出一条，危险度致命）：五色真龙（壮年）或贝希尔 / 死亡骑士带随从。
- 报酬：银子 = 点数 × 0.7 × 危险度倍率（0.8 / 1 / 1.3 / 1.7）×（1 + 名声 / 200）；40% + 15% × 危险度 一张法术卷轴；5% 一二阶湖印结晶；高 / 致命 1% 一枚六环通用秘传结晶；名声 +2 / +3 / +5 / +6；参与者经验 = 点数 × 0.5（每人）。空投到殖民地。
- 参与者：委托地点地图存在期间到过那里的殖民者（每 250 刻记一次）；都没有就算当时地点地图上的殖民者。
- 湖畔委托：魔力湖泊不敌对时，每次刷新 25% 有一条由魔力湖泊发出（标题前缀「湖畔委托·」），报酬必有一枚一阶湖印结晶，完成后好感 +10～15。
- 名声 0～100，无名 0 / 小有名气 20 / 知名 45 / 威名远扬 70 / 传奇 90，显示在窗口顶部的名声条上。
- 窗口：顶部名声条和说明；每条委托显示危险度色块、类型和敌人、推荐等级 / 距离 / 威胁点数 / 剩余天数、敌人、报酬，悬停看完整说明；「接受」点两次确认（没有浮动菜单、不用选接取人）。已接委托显示状态和「定位地点 / 定位目标」。

## 决定与偏差
- 告示板没有新画贴图，用了探索公告板的贴图（Graphic_Multi，1×2 摆放），石料 / 木材颜色不会染到贴图上。遗物用秘传结晶的贴图染成金色，亡灵之源用力场柱贴图染成暗绿色。
- 救援的冒险者属于一个友方派系（不是无派系），这样原版能「救援」他；选「领赏」后他养好伤会按原版规则自己离开。
- 寻回失物：遗物在远征队的商队里不算完成，要回到殖民地地图上。
- 通缉犯的名字只是给首领加个外号（例如「血手」），没有新的派系。
- 「三条里至少一条低或中」靠最后一条强制低 / 中实现。
- 任务不能在告示板上放弃（与原版已接任务一致）；用开发者工具结束任务时只收拾地点，不扣名声。
- 冒险委托板和 1.71.0 的探索公告板互相独立，名声只属于委托板。没有用到 Isekai。
