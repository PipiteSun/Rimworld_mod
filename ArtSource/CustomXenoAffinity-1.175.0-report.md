# 1.175.0 种族亲和编辑支持自设异种 报告（2026-11-17）

需求（Peter）：现在我单独设置种族的属性依赖，我想要加入对于自设种族的属性亲和。

理解：「自设种族」= 用原版异种编辑器自己做的异种（没有定义文件，只有名字和基因）。以前这类异种在「种族亲和编辑」里没有行，一律按人类算。

## 做了什么
- 「种族亲和编辑」窗口里多出来源为「自设异种」的行，排在「人类（兜底）」后面、DND 种族前面。每行和别的种族一样能配六维擅长 / 笨拙、传奇擅长、传奇种族，「默认」恢复成按人类算。
- 列出的名字来自四处：异种文件夹里保存的自设异种、本局游戏里记着的、地图和世界上的人身上带的、以及以前已经配过的。
- 带这个自设异种的人会用你配的那一行；没配过的照旧按人类（或神兽血裔那类血脉基因）算。
- 配置仍存在模组设置里，跨存档通用。

## 要注意的
- 是按异种的**名字**认的：异种改名后要重新配；不同存档里同名的自设异种共用一条。
- 窗口打开时才收集名字，游戏里新做了一个异种后要关掉窗口重开才会出现。
- 新加的几句界面文字没有英文翻译（这个窗口原来的文字本来也没有英文）。
