# DND 专长加强构思（1.67.0）

## 一、为什么现在专长不值得选

1.65.0 之后六维是 3.5 版乘法曲线（10 = ×1，16 = ×2.3，18 = ×3，20 = ×4，24 = ×7）。一次属性提升 = 主属性 +2，大约让这项属性的**所有效果再 ×1.3**：
- 力量 16→18：近战伤害、负重、采矿 ×2.3 → ×3
- 敏捷 18→20：射击精度、近战命中、移速 ×3 → ×4，瞄准时间更短
- 体质 +2：伤口愈合、免疫、护甲、疼痛休克阈值一起涨

而现在的专长大多是 5%～15% 的单项小效果，或者一天一次的触发（坚韧 1 次止血、治疗者包扎 ×1.15、灵活移速 +0.2、观察者研究 +10%）。在 4/8/12/16 级二选一的时候，属性提升几乎永远更好。敌人 50% 选专长，等于敌人也在变弱。

## 二、总规则（所有专长通用）

1. **每个专长附带 +1 属性**（照 5e 2024 的“半专长”）。每个专长写 1～3 个可选属性，选专长时自动加在其中**当前最高**（职业主属性优先）的那一项。
   - 这 +1 和武艺天赋一样加在上限之后（上限也跟着 +1），不会因为到顶而浪费。
   - 旧存档里已经选过的专长读档时自动补上这 +1。
   - 冒险者分页里属性显示成「18+1」，悬停说明来自哪个专长。
2. **数值大约翻倍**，并且几个核心专长**随熟练加值成长**（2 级 +2 … 20 级 +6，传奇 +7/+8），后期不掉队。
3. 结果：专长 ≈ 半次属性提升 + 一个有特色的规则效果。和 +2 属性大致持平，适合有明确玩法的人。
4. 敌人仍然 50% 选专长（会变强一些，影响不大，袭击点数不改）。

## 七、实现要点

- `LP_FeatDef` 加 `bonusAbilities`（如 `Str,Dex`）；冒险者状态存 `featAbility`（专长 → 加在哪项），`Eff()` 在上限之后加上；`PostLoad` 给旧专长补选。
- 熟练加值成长：幸运次数、重甲减伤、坚韧血量由代码读 `h.Proficiency` / `h.level`。
- 数值常量集中在 `Feats` / `Feats2` 的 const；描述文字同步改，全部用“成功率 X% / ×N / +N”的写法，不出现骰子词。
- 新专长图标 8 个，照现有专长图标风格画。
- 测试：`-Only Feats2,Adventurer`（新增约 12 条检查）。不跑全套。
- 备份 `ArtSource/backup-<上一版>`，报告 `ArtSource/FeatsBuff-1.67.0-report.md`，About + 使用说明加更新记录。
