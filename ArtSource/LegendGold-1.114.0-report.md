# 传奇种族也能获得传奇特性（1.114.0 热修，2026-11-04）

Peter：「让传奇种族可以获得传奇特性，但是概率比普通种族低。」

## 改动
- 生成时金色强力特性（英雄之资、极致、四个天命）出现率：普通种族 1%、中等 0.4%、**传奇种族 0.2%（原来 0%）**，再乘「强力特性出现率」。池子和其他种族相同，六个都能出。
- 剧情首领 / 宿敌冠军带强力特性时：传奇种族 **25% 是金色**（原来只出紫色）；人类仍优先金色，其他种族各半。
- 「额外强力特性」连抽也按新的比例，所以传奇种族的额外一个也可能是金色。
- 设置「DND 强力特性」说明改为「传奇种族 0.2% / 1%」。
- 未改：传奇种族紫色池（仍不抽改加点倍率的那几个）、四个稀有天赋（传奇种族仍没有）、诅咒之力比例。
