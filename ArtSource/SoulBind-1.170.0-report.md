# 1.170.0 封魂入器 报告（2026-11-17）

需求（Peter）：能不能把 pawn 的灵魂转移到武器里当器灵？想让囚犯在武器里受折磨，最好显示加心情。

## 现状调查
DND 里原来没有把灵魂封进武器的功能。相关的只有：深渊法阵「炼魂」（囚犯 → 3 枚灵魂币）、半巫妖掉的灵魂宝石、巫妖命匣「汲取灵魂」（尸体）。这次接在 1.168.0 的人格武器上做。

## 做了什么
- 附魔台「附魔强化」窗口 → 选中 +5 以上的武器 → 「人格」一节 →「封魂入器…」→ 选地图上的囚犯（列表显示会得到的人格和初始共鸣）→ 确认。
- 材料同唤醒人格（6 精金 + 20 黄金），工匠智识 10，不会失败。囚犯死去（留下尸体）。
- 人格按囚犯决定：特性优先（好斗→狂怒，坚韧→守护，变态杀人狂/嗜血→嗜血），否则看最高技能（近战→嗜血，射击→猎手，智识→智者，社交→王者，艺术→静谧，建造/采矿/医疗→守护，驯兽/种植→迅影，其他→狂怒）。
- 武器名 = 囚犯名字；初始共鸣 = 最高技能 ×2（取和原共鸣的较大值）；物品信息显示「器灵：某某的灵魂，正在受折磨」。
- 心情：羁绊者拿着时「器灵在哀嚎」+5（叠加人格武器本身的 +3/+5/+7）；封魂时地图上对囚犯好感 ≤ -10 的殖民者「仇人在受折磨」+8，15 天（最多叠 3 次）。
- 「重塑人格」会放走器灵，变回普通随机人格。
- 没有扣派系好感，也没有给殖民者负面心情。
