# 制伏武器（非致命抓捕武器）实现要求 — 1.61.0

> 原始需求写的是 1.62.0；由于计划中的 1.61.0 夺魂仪式已暂停，本内容改用 1.61.0 版本号（报告 Nonlethal-1.61.0-report.md，测试组 Nonlethal）。

## 一、核心规则：自有 hediff，绝不致命
- DamageDef（均使用 DamageWorker_LPSubdue：不造成伤口、不流血、不断肢、不损坏衣物；只给 hediff LP_Subdued 增加严重度）：
  - LP_Subdue 制伏打击（armorCategory Blunt；短棍、网）
  - LP_SleepMagic 安眠魔法（无护甲；安眠箭、安眠法杖、安眠粉）
- 增量 = 伤害 × 设置倍率 ÷ (40 × 体型 × 生命值倍率)。人类：短棍一击约 0.30，3–4 击倒地。
- LP_SleepMagic 额外 × (1 − 心智抗性)（精灵 50% → 一半；≥100% 免疫）。
- 免疫（浮字「免疫制伏」）：机械体、非血肉、死灵造物、巫妖、已倒地目标。严重度上限 1.3。
- Hediff LP_Subdued「制伏」阶段：
  - 0.01 晕眩（移动 −10%，操作 −10%）
  - 0.4 摇摇欲坠（意识上限 70%，移动 −30%）
  - 0.7 快撑不住（意识上限 40%，移动 −50%）
  - 1.0 昏迷倒地（意识 setMax 0.10 — 倒地；意识 0 会致死，所以不为 0）
- 不是伤口：无需治疗、不感染。恢复 HediffComp_SubdueRecover：最后一次制伏伤害后 1 小时内不衰减，之后每小时 −0.1（满 1.3 约昏迷 4 小时）。俘虏醒来后仍是俘虏。其他来源的真实伤口仍按原版规则（描述中写明）。
- 防卡死：后置补丁 WorkGiver_HunterHunt.HasHuntingWeapon → 主武器为非致命武器时返回 false。手动攻击已倒地目标无效果，浮字「已经昏迷了」。
- 设置「制伏伤害倍率」50%–200%，默认 100%。

## 二、研究
LP_Research_Subduing 制伏战术，页签 LP_FireGiantTech，坐标 1,4.9（被占则同行右移；前置必须在左侧），前置 符文锻造 LP_Research_RuneSmithing，费用 800；解锁短棍、缚网弩、安眠短弓、安眠粉囊。安眠法杖另需既有的 奥术法杖 研究。

## 三、武器
描述结尾统一：「非致命：只会让目标昏迷倒地，不会造成伤口，也不会杀死目标。适合抓俘虏。」
1. LP_SubduingCudgel 制伏短棍：单手近战，LP_Subdue 12，冷却 1.6 秒；第二攻击 戳击 9。工作台 符文铁砧。木 40、钢 20（可用木质材料）。外观：皮革缠绕的短棍，铁箍上刻安眠符文。
2. LP_NetCrossbow 缚网弩：射程 22，瞄准 1.2 秒，冷却 2.6 秒；弹药 束缚网：LP_Subdue 8 + 眩晕 2.5 秒 + hediff LP_Netted（移动 −50%，6 秒）。符文铁砧。木 50、钢 30、布 30。外观：沉重木弩，枪托上盘着灰色绳网。
3. LP_SleepBow 安眠短弓：射程 26，瞄准 1.0 秒，冷却 1.8 秒；LP_SleepMagic 10。符文铁砧。木 60（可用木质材料）、秘银 3。外观：深绿短弓，淡紫箭羽，箭头带发光紫粉。
4. LP_SleepStaff 安眠法杖：遵循 1.29.0 法杖规则（魔法系数取自心灵敏感度、每发心灵熵、敏感度 0 无法使用、驱魔粉阻挡）——弹药继承既有 LP_ArcaneBullet，伤害类型 LP_SleepMagic；射程 28，瞄准 1.0 秒，冷却 2.2 秒，LP_SleepMagic 16 × 魔法系数。附魔台。木 40、秘银 8、零部件 1。外观：弯曲的灰白木杖，月牙托着淡紫水晶。
5. LP_SleepDustPouch 安眠粉囊：像原版手雷一样可重复投掷：射程 12，冷却 8 秒；半径 2.4 爆散，对范围内所有血肉生物（含友军）LP_SleepMagic 22，紫色粉尘云。符文铁砧。布 20、秘银 2、草药 2。外观：扎口紫布袋，冒出紫粉。
- 器械师门槛（1.43.0 规则）：5 件全部加入 Artificer.RequiredAbility，「奥术工坊」层级；无 VPE → 无门槛。
- 商人：奴隶贩/海盗商队（原版 Caravan_Outlander_PirateMerchant，若有 DND 黑市商人也加）约 25% 概率各带 1 把短棍和缚网弩。
- 不给 NPC 派系。

## 四、文件
Defs/Nonlethal.xml（2 个 DamageDef、LP_Subdued、LP_Netted、5 武器、弹药、5 配方）；研究写入 Defs/Research.xml；Source/Nonlethal.cs；Source/NonlethalChecks.cs；Artificer.cs 条目。

## 五、测试（-Only Nonlethal）
1. 所有 def 加载 + 贴图存在
2. 人类反复受短棍伤害：倒地、零伤口、存活；再打 20 下仍存活
3. 满值后：1 小时内不衰减，之后每小时 −0.1，醒来
4. 精灵受安眠魔法只有一半；机械体、死灵造物、巫妖免疫
5. 体型 2 巨人增量减半
6. 网：眩晕 + LP_Netted 移动 −50%
7. 持非致命武器的猎人 HasHuntingWeapon 为 false
8. 倒地者 CanCapture 为 true，被抓俘虏保留 LP_Subdued 并按时醒来
9. （-VPE）没有奥术工坊的小人不能制作安眠法杖

## 六、需记录的决定
自有 hediff 而非原版疼痛/眩晕（原版钝击会骨折/头部致命伤）；意识上限 10% 而非 0；无视疼痛（止痛药无效）；体型与生命值倍率计入；亡灵和机械免疫，精灵按心智抗性减半；粉囊伤友军；不给敌人；无新能力；猎人排除。
